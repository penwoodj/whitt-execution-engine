To retrieve the human-readable file sizes for each `.txt` file listed in the previous step using the `du -h --files-size` command, you can execute the following command:

```bash
du -h --files-size *.txt
```

This command will list each `.txt` file along with its size in a human-readable format. The output will look like this:

```
filename1.txt 10K
filename2.txt 256M
filename3.txt 5G
...
```

Replace `filename1.txt`, `filename2.txt`, etc., with the actual filenames from your data.
