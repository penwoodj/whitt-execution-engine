To extract filenames that end with ".txt" from the list of files in the home directory using a shell command, you can use the following command:

```sh
ls -1 ~/ | grep '\.txt$'
```

This command does the following:
- `ls -1 ~/`: Lists all files and directories in the home directory (`~`) with one file per line.
- `grep '\.txt$'`: Filters the output to include only lines that end with ".txt". The `\.` is used to escape the dot, and `$` ensures that the match occurs at the end of the line.

Make sure you have the necessary permissions to access the home directory. If you encounter any permission issues, you might need to use `sudo`:

```sh
sudo ls -1 ~/ | grep '\.txt$'
```

This will prompt for your password and execute the command with superuser privileges.
