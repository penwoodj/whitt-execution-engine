To analyze each Markdown file listed in `{{step_01_read_files.output}}` and extract the full content and structural hierarchy, we need to parse the files for headers, paragraphs, lists, and code blocks. We will then construct a JSON array where each entry includes the filename and a parsed content object with fields: "headers", "body_text", and "sections". Here's how you can achieve this:

1. **Read the Markdown Files**: First, read each file listed in `{{step_01_read_files.output}}`.
2. **Parse Headers**: Identify and extract all headers (e.g., #, ##, ###).
3. **Extract Paragraphs**: Collect all non-header text into paragraphs.
4. **Identify Lists**: Detect and parse lists (bulleted or numbered).
5. **Extract Code Blocks**: Locate and capture code blocks for further processing if needed.
6. **Structure the Output**: Organize the extracted content into a JSON array with the required fields.

Here's an example of how you might implement this in Python:

```python
import os
import re

def parse_markdown(file_path):
    headers = []
    body_text = ""
    sections = []

    with open(file_path, 'r', encoding='utf-8') as file:
        lines = file.readlines()

    current_section = None
    for line in lines:
        # Check for headers
        match = re.match(r'^#+\s+(.*)$', line)
        if match:
            header_level = len(match.group(0))
            header_text = match.group(1).strip()
            headers.append((header_level, header_text))

            # Start a new section for the header
            current_section = {
                'level': header_level,
                'text': header_text,
                'content': []
            }
            sections.append(current_section)

        # Check for paragraphs
        elif line.strip():
            if current_section:
                current_section['content'].append(line.strip())

    return headers, body_text, sections

def process_files(file_paths):
    parsed_content = []

    for file_path in file_paths:
        filename = os.path.basename(file_path)
        headers, body_text, sections = parse_markdown(file_path)

        # Construct the output object
        content_object = {
            "headers": headers,
            "body_text": body_text,
            "sections": sections
        }

        parsed_content.append({
            "filename": filename,
            "content": content_object
        })

    return parsed_content

# Example usage
file_paths = ['path/to/file1.md', 'path/to/file2.md']  # Replace with actual file paths
parsed_content = process_files(file_paths)
print(parsed_content)
```

### Explanation:
- **Headers**: We use a regular expression to match lines that start with one or more `#` characters followed by text. This helps us identify headers of different levels.
- **Paragraphs**: Non-empty lines not starting with a header are considered paragraphs and added to the current section's content.
- **Sections**: Each section is represented as an object containing the header level, text, and its content.
- **Output**: The function `process_files` reads each file, parses it, and constructs a JSON-like structure for each file.

This approach ensures that the markdown syntax is removed from the output, leaving only plain text content with proper hierarchical organization.
