To compute the total word count for each markdown file listed in `{{step_01_read_files.output}}` using a shell command with `awk`, you can follow these steps:

1. Iterate over each file listed in `{{step_01_read_files.output}}`.
2. For each file, read its raw text.
3. Use `awk` to count the words by processing each line and summing the number of characters between spaces, excluding punctuation.

Here's a shell command that accomplishes this:

```sh
for file in $(cat {{step_01_read_files.output}}); do
  # Read the content of the file
  content=$(< "$file")
  
  # Use awk to count words
  word_count=$(echo "$content" | tr -d '[:punct:]' | wc -w)
  
  # Output the filename and word count in the required format
  echo "${file}:${word_count}"
done
```

### Explanation:

- `for file in $(cat {{step_01_read_files.output}})`: This loop iterates over each file listed in `{{step_01_read_files.output}}`.
- `< "$file"`: Reads the content of the current file.
- `tr -d '[:punct:]'`: Removes all punctuation characters from the text, which helps in accurately counting words.
- `wc -w`: Counts the number of words in the processed text.
- `echo "${file}:${word_count}"`: Outputs each filename followed by its word count in the required format.

This command will output a newline-separated list of filenames and their corresponding word counts.
