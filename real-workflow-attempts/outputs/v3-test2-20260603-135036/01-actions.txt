2. Find all .txt files in /tmp using shell find command  
3. For each .txt file, read its content using shell cat command  
4. Count the number of lines in each file using shell wc -l command

6. Sort the list by line_count in descending order  
7. Format the data into CSV with columns: filename, line_count  
8. Output the CSV to standard output
