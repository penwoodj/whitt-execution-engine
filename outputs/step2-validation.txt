To validate the column types and constraints of the CSV file, we need to perform additional checks beyond just ensuring the number of columns matches the header. This includes checking for missing or invalid values, validating data types, and applying any specified constraints (e.g., minimum length, maximum value).

Here's an updated version of the code that includes these additional checks:

```python
import csv

def read_csv_with_headers(file_path):
    try:
        # Open the CSV file in read mode
        with open(file_path, mode='r', newline='') as file:
            reader = csv.reader(file)
            
            # Read and display the headers
            headers = next(reader)
            print("Headers:", headers)
            
            # Check if each row has the correct number of columns
            for row in reader:
                if len(row) != len(headers):
                    raise ValueError(f"Row with {len(row)} columns does not match the expected {len(headers)} columns.")
                
                # Validate data types and constraints
                for i, value in enumerate(row):
                    column_name = headers[i]
                    
                    # Example constraints: integer, float, string with minimum length
                    if column_name == 'age':
                        try:
                            int(value)
                        except ValueError:
                            raise ValueError(f"Invalid age value '{value}' in row {i+1}. Expected an integer.")
                        
                        if int(value) < 0:
                            raise ValueError(f"Age cannot be negative in row {i+1}.")
                    elif column_name == 'name':
                        if len(value) < 2:
                            raise ValueError(f"Name must have at least 2 characters in row {i+1}.")
                    # Add more constraints as needed
                    
                    # Display the validated row
                    print("Row:", row)
    
    except FileNotFoundError:
        print(f"The file '{file_path}' was not found.")
    except csv.Error as e:
        print(f"An error occurred while reading the CSV file: {e}")
    except ValueError as ve:
        print(f"Validation error in row {ve.args[1]}: {ve}")

# Example usage
file_path = 'example.csv'
read_csv_with_headers(file_path)
```

### Explanation:

1. **Data Type Validation**:
   - For the `age` column, we attempt to convert each value to an integer and check if it is non-negative.
   - For the `name` column, we ensure that each name has at least 2 characters.

2. **Constraints Application**:
   - You can add more constraints by checking for specific patterns, ranges, or other conditions as needed.

3. **Error Handling**:
   - The code now includes a try-except block to catch and handle `ValueError` exceptions that occur during data validation.
   - This allows you to provide detailed error messages indicating which row and column caused the issue.

This updated code will help you ensure that your CSV file meets specific requirements, such as valid data types and constraints, by providing clear feedback on any issues found.
