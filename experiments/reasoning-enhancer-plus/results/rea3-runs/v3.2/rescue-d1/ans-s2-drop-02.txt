Let’s define variables:

- Let M = number of features Mike shipped this cycle.
- Rosa claims credit for 2, but we don’t know how many she actually shipped; we only care about Mike.
- Petra shipped 5 more than Mike did last cycle but only 4 this cycle.

We are told: “Petra shipped 5 more than Mike did last cycle but only 4 this cycle.”

This means:
- Petra’s this-cycle count = 4
- Petra’s this-cycle count = (Mike’s last-cycle count) + 5

So:
4 = (Mike’s last-cycle count) + 5  
→ Mike’s last-cycle count = 4 - 5 = -1

Now, we know Mike shipped 3 features total across both cycles. So:

Mike’s last-cycle count + Mike’s this-cycle count = 3  
-1 + M = 3  
M = 3 + 1 = 4

Answer: 4
