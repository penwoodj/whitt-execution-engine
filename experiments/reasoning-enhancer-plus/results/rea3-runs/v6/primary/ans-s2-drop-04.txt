To determine which quarterback averaged more yards per game through four games only, we calculate the average for each player based on their performance in games 1 through 4.

**Step 1: Calculate Ade's average yards per game (Games 1-4)**
*   Yards thrown: 285, 310, 264, 342
*   Sum of yards = $285 + 310 + 264 + 342 = 1201$
*   Number of games = 4
*   Average = $1201 / 4 = 300.25$

**Step 2: Calculate Beto's average yards per game (Games 1-4)**
*   Yards thrown: 301, 296, 250, 388
*   Sum of yards = $301 + 296 + 250 + 388 = 1235$
*   Number of games = 4
*   Average = $1235 / 4 = 308.75$

**Step 3: Compare the averages and find the difference**
*   Beto's average (308.75) is greater than Ade's average (300.25).
*   Difference = $308.75 - 300.25 = 8.5$

Beto averaged more yards per game by 8.5.

Answer: Beto by 8.5
