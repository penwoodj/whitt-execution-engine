```python
# Calculate the number of batches needed for a job that requires 140 tasks.
tasks_per_batch = 35
total_tasks_needed = 140

# Determine how many batches are required to complete all tasks.
batches_required = total_tasks_needed / tasks_per_batch

# Since each batch takes one minute, the time taken is equal to the number of batches.
time_taken_minutes = batches_required

# Print the result with the unit.
print(f"{int(time_taken_minutes)} minutes")
```
