```python
# Define a list of tickets with their priorities
tickets = [
    {"id": "INC-7", "priority": 2},
    {"id": "INC-2", "priority": 1},
    {"id": "INC-5", "priority": 0}
]

# Sort the tickets by priority in ascending order (P0 before P1 before P2)
sorted_tickets = sorted(tickets, key=lambda x: x["priority"])

# Print the ticket ids in execution order
for ticket in sorted_tickets:
    print(ticket["id"])
```
