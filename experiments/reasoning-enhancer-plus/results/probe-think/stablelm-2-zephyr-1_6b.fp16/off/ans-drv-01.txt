To determine how many events per queue, we first need to calculate the total number of unique events after removing duplicates.

Since there were 100 events in total and they were processed in batches of 50 (with 20 being removed as duplicates), we can find the number of unique events by dividing the total number of events by the batch size:

100 events / 50 events per batch = 2 batches

Since each batch processed 20 duplicate events, there were a total of 40 duplicate events. Therefore, to find the number of unique events in one batch (before splitting evenly across queues):

20 duplicate events / 20 events per batch = 1 event per batch

Now that we know there is only one event per batch, we can divide this by the number of queues (which is also 4) to find out how many events are split evenly among the queues:

1 event per batch / 4 queues = 0.25 events per queue
