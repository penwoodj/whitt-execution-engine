To determine the number of minutes until the completion of all jobs, we need to find out how many batches of 5 tasks each machine can process per minute.

Since there are 7 machines handling 5 tasks each per minute, the total number of tasks processed by all machines in one batch is:

7 machines * 5 tasks = 35 tasks

Now, if a job requires 1 task to be completed, then the number of batches needed to complete all jobs can be found by dividing the total number of required tasks (1 for each job) by the number of tasks processed per batch:

Total tasks / Tasks per batch = Number of batches
35 tasks / 5 tasks = 7 batches

Since one batch completes 5 tasks per minute, we can calculate the time needed to complete all jobs by multiplying the number of batches by the number of tasks in each batch:

Number of batches * Tasks per batch = Time until done
7 batches * 5 tasks = 35 minutes

Therefore, it will take 35 minutes until all jobs are completed.
