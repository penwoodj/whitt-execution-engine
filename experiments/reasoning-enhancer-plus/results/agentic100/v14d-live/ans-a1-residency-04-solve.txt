Let's go step by step through every rule and compute the values accurately.

---

**Step 1: Understand the rules**

We have a system with:

- A **residency cap**: 8 GB. This means at any time, only models that are resident (loaded in memory) must not exceed 8 GB total.
- Jobs run **strictly in order**: A → B → C → D
- Each job requires a model of specific size:
  - Job A: needs 5 GB model
  - Job B: needs 3 GB model
  - Job C: needs 5 GB model
  - Job D: needs  3 GB model
- Both models **begin loaded** — this means at the start, both models are already in memory.
- After each job finishes, its model is **unloaded for maintenance**. This happens after each job (including possibly after D).
- Each **load** costs 30 seconds.
- Each **unload** costs 10 seconds.
- The dashboard service does not change anything — it just observes.

We are to compute:
- Total number of **loads**
- Total time spent on **loading** (in seconds)
- Total time spent on **unloading** (in seconds)

Note: "loads" refers to how many times a model is loaded into memory. Since models start already loaded, we only count loads that happen during the schedule.

---

**Step 2: Track job execution and memory state**

We must ensure that at the start of each job, its required model is resident (loaded in memory). The system has an 8 GB cap — so total memory usage at any time must not exceed 8 GB.

Let’s go through jobs one by one:

---

**Initial State:**
- Both models are already loaded.
- So we have two models in memory:
  - A model (5 GB)
  - B model (3 GB)
- Total memory = 5 + 3 = 8 GB → exactly at cap. This is acceptable.

Now, jobs run in order:

---

**Job A: needs 5 GB model**

- Already has the 5 GB model loaded → no need to load it again.
- So **no new load** for job A.
- After job A finishes, its model must be unloaded (for maintenance).
- Unload cost = 10 seconds.

→ So after A: unload of A's model (5 GB) → memory now only has B’s 3 GB model.

---

**Job B: needs 3 GB model**

- Already has the 3 GB model loaded → no need to load it.
- So **no new load** for job B.
- After job B finishes, its model is unloaded.
- Unload cost = 10 seconds.
