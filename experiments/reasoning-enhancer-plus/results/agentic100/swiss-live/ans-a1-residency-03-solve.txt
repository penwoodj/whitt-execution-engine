### Step 1: Understand the setup

We have a sequence of jobs that run in strict order:

- Job A: needs 3 GB model (call it m1)
- Job B: needs 5 GB model (call it m2)
- Job C: needs m2 again

**Initial state**: Only **m2** is loaded at the start.  
**m1 is not loaded initially**.

Each job runs only when its required model is resident (loaded) at the start of execution.

After each job finishes, its model is unloaded for maintenance.

Rules:

- **Load cost**: 30 seconds per load
- **Unload cost**: 10 seconds per unload
- A load happens **only if** the required model is not already resident when the job starts.
- An unload happens **after every job finishes**, regardless of whether it was loaded or not (but only for the model that ran).
- The model must be resident at start — so if a job needs a model and it's not there, we load it.

We are to count:
- Total number of loads
- Total load time in seconds
