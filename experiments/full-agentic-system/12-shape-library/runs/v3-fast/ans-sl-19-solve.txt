**Phase 1 RULE SCAN**
1. Load Rule: A load command attempts to add a model of specified size; if it fits in remaining free space, the model is added and marked resident (unpinned unless pinned), moving it to most-recent position.
2. Eviction Rule: If a load does not fit, the system evicts least-recently-touched UNPINNED models one by one until enough space exists; each eviction increments the eviction counter.
3. Deferral Rule: If a load cannot fit even after all unpinned models are evicted (only pinned models remain), the load is deferred (no eviction occurs for this specific load), and its ID is recorded in the deferred list.
4. Unload Rule: An unload command frees the specified model's size from the pool; if the model is not resident, it is a no-op.
5. Pinning Constraint: Model B is pinned and never evicted under any circumstances.
6. Touch Update Rule: Every time a model is loaded or touched (during eviction checks), its recency is updated to most-recent.
