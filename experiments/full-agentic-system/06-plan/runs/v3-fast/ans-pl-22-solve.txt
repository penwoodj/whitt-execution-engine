**Phase 1 RULE SCAN**
1. Load Rule: A load fits if `current_free >= requested_size`; otherwise, it triggers eviction logic.
2. Eviction Logic: If a load cannot fit, evict the Least-Recently-Touched (LRT) **unpinned** model one at a time until space is available or only pinned models remain.
3. Deferral Rule: If after exhausting all unpinned evictions the requested size still does not fit (only pinned models remain), the load is deferred (no eviction count for this step).
4. Touch Rule: Every successful load, partial load, or eviction touch moves the model to Most-Recently-Touched (MRT).
5. Unload Rule: An unload frees the specified size immediately; if the model is not resident, it is a no-op.
6. Expiry/Return Rule: Not applicable as there are no expiring grants in this stream (all requests are fresh loads/unloads).
