**Phase 1 RULE SCAN**
1. **Arrival Rule**: A load request attempts to place a model of size $S$ into available memory; if it fits, state updates immediately.
2. **Eviction Trigger (Fit Check)**: If the requested model does not fit in current free space, an eviction process is initiated.
3. **Eviction Selection (LRU Unpinned)**: The system identifies unpinned models sorted by Least Recently Used (LRU); pinned models are ignored for selection.
4. **Eviction Execution**: Selected unpinned models are unloaded one by one until enough free space exists to fit the requested model.
5. **Deferred Load Condition**: If after unloading *all* available unpinned models, the requested model still does not fit (only pinned models remain), the load is deferred.
6. **Counting Rules**: Every successful eviction increments the `evictions` counter; every deferred load increments the `deferrals` counter and adds its ID to the `deferred` list.
7. **No-Op Rule**: Unloading a model that is not currently resident (already evicted or never loaded) results in no state change and no count increment.
