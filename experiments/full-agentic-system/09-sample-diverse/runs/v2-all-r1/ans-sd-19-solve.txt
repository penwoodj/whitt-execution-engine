### Phase 1 RULE SCAN

The following rules govern the state changes during the event stream:

1.  **Arrival/Load Rule**: Upon request of a model $M$ with size $S_M$, if current free space $\ge S_M$, load $M$. If successful, increment `loads`.
2.  **Eviction Selection Rule**: If current free space $< S_M$, identify the set of unpinned resident models. Sort them by recency (Least Recently Touched first).
3.  **Eviction Execution Rule**: Evict the LRU unpinned model one at a time, subtracting its size from the required load and adding it to free space, incrementing `evictions` for each eviction performed. Repeat until either the load fits or no unpinned models remain.
4.  **Deferral Rule**: If after exhausting all unpinned evictions, remaining free space $< S_M$, defer the load. Record the request ID in `deferred`, increment `deferrals`. Do not perform any further evictions (even of pinned models).
5.  **Recency Update Rule**: Upon a successful load or an eviction, update the recency list: the touched model(s) move to the most-recent position; previously resident unpinned models shift down in order.
6.  **Unload Rule**: Upon request to unload model $M$, if $M$ is resident, subtract its size from free space and remove it from residents. If $M$ is not resident (already evicted or never loaded), perform a no-op.
