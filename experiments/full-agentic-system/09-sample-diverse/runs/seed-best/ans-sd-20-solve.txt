### Phase 1: RULE SCAN
The following rules govern the state changes during the event stream. Each rule is listed on one line with its trigger condition.

1.  **Load Rule**: Triggered by a `load` request; if capacity allows, loads the model and updates recency (moves to most-recent).
2.  **Eviction Selection Rule**: Triggered when a load cannot fit; selects the least-recently-touched *unpinned* model for eviction.
3.  **Eviction Execution Rule**: Triggered by selection; evicts the selected unpinned model, freeing its space and updating recency (evicted model removed from list).
4.  **Deferred Load Rule**: Triggered when a load cannot fit even after exhausting all *unpinned* models (only pinned remain); defers the load without eviction.
5.  **Unload Rule**: Triggered by an `unload` request; frees the specified model's space if resident, updates recency (moves to most-recent).
6.  **Recency Update Rule**: Triggered by any successful load or unload; moves the touched model to the end of the recency list.
