### Phase 1 RULE SCAN
The following rules govern state changes during the event sequence. Each rule is listed on one line with its trigger condition.

1. **Arrival Rule**: Triggered by every request ID ($r_1$ through $r_7$) arriving in strict order; attempts to deduct the requested amount from the pool.
2. **Partial Grant Rule**: Triggered when a request arrives and the pool balance is greater than 0 but less than the requested amount; grants the full remaining pool balance (pool drops to 0).
3. **Denial Rule**: Triggered only if a request arrives while the pool balance is exactly 0; denies the request and leaves the pool at 0.
4. **Expiry Return Rule**: Triggered immediately after Request $r_2$ completes; returns $\lfloor \text{granted amount to } r_1 / 2 \rfloor$ to the pool before processing any subsequent requests.
