### Phase 1: RULE SCAN
The following rules govern the state changes during the event stream. Each rule is listed on one line with its trigger condition.

1.  **Load Rule**: Triggered by a `load` request; if the requested model fits in free space, it loads immediately (no eviction).
2.  **Eviction Selection Rule**: Triggered when a load cannot fit; selects the Least-Recently-Touched (LRT) *unpinned* model for eviction.
3.  **Eviction Execution Rule**: Triggered by selection; evicts one unpinned model, freeing its space, and increments the `evictions` counter.
4.  **Deferred Load Rule**: Triggered when a load cannot fit even after evicting all available *unpinned* models (only pinned remain or no space); the load is deferred, incrementing `deferrals`, recording the ID in `deferred`, and adding no space.
5.  **Unload Rule**: Triggered by an `unload` request; frees the model's size if resident (no-op if not resident).
6.  **Recency Update Rule**: Triggered on any load or eviction of a specific model; that model moves to the Most-Recently-Touched position in the recency list.
