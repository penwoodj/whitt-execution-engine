**Phase 1 RULE SCAN**
- Load Event: Adds a model to resident set if capacity allows; triggers eviction of LRU unpinned models if load size > remaining free space.
- Eviction Rule: Removes least-recently-touched (LRU) *unpinned* models until enough space exists for the incoming load.
- Pinned Constraint: Model B is pinned and never evicted.
- Capacity Check: A load cannot fit only if `load_size > current_total_capacity - load_size`. If it fits, no eviction occurs regardless of other factors.
- Deferred Load Rule: A load is deferred *only* after all possible LRU unpinned models have been evicted and the load still does not fit. The deferred ID is the load's own ID.
- Unload Event: Removes a model from resident set if present; no-op if already absent or pinned (though B is pinned, unloading it implies removal of its footprint).
- Capacity Update Rule: Total capacity decreases by `unload_size` upon successful unload; increases by `load_size` upon successful load.
- Counting Rule: Evictions count every model removed during the eviction process. Deferrals count only completed deferral events. Loads count total load attempts (successful or deferred).
