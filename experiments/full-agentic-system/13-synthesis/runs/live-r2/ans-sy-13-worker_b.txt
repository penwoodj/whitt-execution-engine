### Phase 1: Rule Scan (Part B - Residency)

Based on the task description for the "second matter" (Part B), here are the rules governing the state changes:

1.  **Initial State:** One 8GB card resident with models A, B, C, D having sizes 1, 4, 2, 6 GB respectively.
2.  **Pinned Model Rule:** Model B is pinned and never evicted.
3.  **Eviction Selection Rule:** Evictions choose the least-recently-touched (LRU) unpinned model.
4.  **Load Execution & Cost Rule:** Loads cost 30s, unloads cost 10s. A load that cannot fit evicts as many LRU unpinned models as needed. If only pinned models remain and it still does not fit, the load defers.
5.  **Counting Rules:**
    *   `loads`: Counts every load command actually executed (including those that later evicted something).
    *   `evictions`: Counts every eviction actually performed (even if the load ends up deferred).
    *   `deferrals`: A load is only deferred after evicting every unpinned resident still leaves too little room. The deferred id is the load's own id.
6.  **No-Op Rule:** An unload for a model no longer resident is a no-op (does not count towards loads/evictions).
