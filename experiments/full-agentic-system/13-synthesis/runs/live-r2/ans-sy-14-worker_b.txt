### Phase 1: Rule Scan (Part B - Residency)

**Rules Identified for Part B:**
1.  **Capacity & Eviction Policy:** One 8GB card; Models A(2), B(2), C(2), D(7) GB resident sizes. Model B is pinned (never evicted). Evictions select LRU unpinned models. Loads cost 30s, Unloads 10s.
2.  **Load Execution Logic:** Loads count every executed command. A load that cannot fit evicts as many LRU unpinned models as needed. If only pinned models remain and it still does not fit, the load defers.
3.  **Eviction/Deferral Counting:** Every actual eviction counts in the total (even if the load ends deferred). A load is only deferred after exhausting all unpinned evictions and room remains insufficient. The `deferred` ID is the load's own ID.
4.  **No-Op Handling:** Unloading a non-resident model is a no-op. Evictions/deferrals are zero if every load fits with room to spare.
