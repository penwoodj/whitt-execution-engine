2.  **Pinned Model Rule:** Model B is pinned and never evicted.
3.  **Eviction Selection Rule:** Evictions choose the least-recently-touched (LRU) unpinned model.
4.  **Load Execution & Cost Rule:** Loads cost 30s, unloads cost 10s. (Note: Costs are tracked but do not affect state counts directly unless specified as a metric; the primary state metrics are loads executed, evictions performed, and deferrals).
5.  **Fit Check Rule:** A load that cannot fit evicts as many LRU unpinned models as needed to make room. If only pinned models remain and it still does not fit, the load is deferred.
6.  **Deferred Load Rule:** A load is deferred if, after evicting every unpinned resident, there is still insufficient room. The deferred ID is that specific load's ID.
7.  **No-Op Unload Rule:** An unload for a model no longer resident is a no-op (does not count towards loads or evictions).
8.  **Zero Eviction/Deferral Condition:** If every load in the stream fits with room to spare, evictions and deferrals stay zero.
