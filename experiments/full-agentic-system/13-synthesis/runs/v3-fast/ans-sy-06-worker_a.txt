### Phase 1 RULE SCAN (First Half Only)
*Rules governing the token pool and request lifecycle for the "release-token pool" event.*

1. **Grant Rule**: A request arriving at a non-zero pool is granted `min(ask, current_pool)` tokens; the pool decreases by that amount. Trigger: Any request arrival ($r_i$).
2. **Denial Rule**: A request arriving when the pool is exactly zero is denied and listed by ID. Trigger: Request arrival where $pool == 0$.
3. **Expiry Rule**: The grant for request $r_2$ expires after request $r_3$ completes. Trigger: Completion of $r_3$.
4. **Return Rule**: Upon expiry, the specific grant from $r_2$ returns `floor(granted_amount / 2)` tokens to the pool. Trigger: Expiry event (post-$r_3$).

### Phase 2 LEDGER WALK (First Half Only)
*Applying events in strict arrival order ($r1 \to r5$).*

**Initial State**: Pool = 50.

1. **Event $r1$ arrives (Ask: 4)**
   - Rule Applied: Grant Rule.
   - Calculation: $\min(4, 50) = 4$.
   - Action: Grant 4 tokens. Pool becomes $50 - 4 = 46$.
   - State: **Pool = 46**

2. **Event $r2$ arrives (Ask: 6)**
   - Rule Applied: Grant Rule.
   - Calculation: $\min(6, 46) = 6$.
   - Action: Grant 6 tokens. Pool becomes $46 - 6 = 40$.
   - State: **Pool = 40** (Grant $r2$ holds 6 tokens).

3. **Event $r3$ arrives (Ask: 9)**
   - Rule Applied: Grant Rule.
   - Calculation: $\min(9, 40) = 9$.
   - Action: Grant 9 tokens. Pool becomes $40 - 9 = 31$.
   - State: **Pool = 31** (Grant $r2$ expires after this event).

4. **Event $r3$ completes $\to$ Expiry Trigger for $r2$**
   - Rule Applied: Expiry Rule then Return Rule.
   - Calculation: Return amount = $\text{floor}(6 / 2) = 3$.
   - Action: Add 3 tokens to pool. Pool becomes $31 + 3 = 34$.
   - State: **Pool = 34**

5. **Event $r4$ arrives (Ask: 13)**
   - Rule Applied: Grant Rule.
   - Calculation: $\min(13, 34) = 13$.
   - Action: Grant 13 tokens. Pool becomes $34 - 13 = 21$.
   - State: **Pool = 21**

6. **Event $r5$ arrives (Ask: 15)**
   - Rule Applied: Grant Rule.
   - Calculation: $\min(15, 21) = 15$.
   - Action: Grant 15 tokens. Pool becomes $21 - 15 = 6$.
   - State: **Pool = 6**

**Final Totals**:
- Total Granted Units: $4 + 6 + 9 + 13 + 15 = 47$.
- Denied List: Empty (pool never hit zero before a request arrived).
- Pool Left: 6.
