### Phase 1 RULE SCAN (First Half Only)
*Rules governing the token pool and request lifecycle for tonight's deploy window.*

1.  **Grant Rule**: Requests arrive in strict order; if the pool has tokens, grant `min(ask, pool)` and subtract from pool. A partial grant is still a granted request.
2.  **Denial Rule**: If the pool is exactly zero upon arrival, deny the request (listed by ID). The denied list stays empty unless this condition is met.
3.  **Expiry Rule**: Grant `r2` expires after `r3` completes; it returns `floor(granted_amount / 2)` to the pool immediately before the next event.

### Phase 2 LEDGER WALK (First Half Only)
*Applying events in strict arrival order.*

**Initial State:** Pool = 55, Granted = 0, Denied = []

1.  **Event `r1` arrives (Ask: 4)**
    *   Rule: Grant `min(4, 55)` = 4.
    *   New Pool: $55 - 4 = 51$.
    *   State: Pool=51, Granted=4.

2.  **Event `r2` arrives (Ask: 7)**
    *   Rule: Grant `min(7, 51)` = 7.
    *   New Pool: $51 - 7 = 44$.
    *   State: Pool=44, Granted=4+7=11.

3.  **Event `r3` arrives (Ask: 11)**
    *   Rule: Grant `min(11, 44)` = 11.
    *   New Pool: $44 - 11 = 33$.
    *   State: Pool=33, Granted=11+11=22.

4.  **Event `r2` Expiry Trigger**
    *   Rule: Grant `r2` expires after `r3`. Return `floor(7 / 2)` = 3 to pool.
    *   New Pool: $33 + 3 = 36$.
    *   State: Pool=36, Granted=22 (Note: Expiry adds back to pool, does not remove from 'granted_units' total count of successful requests).

5.  **Event `r4` arrives (Ask: 13)**
    *   Rule: Grant `min(13, 36)` = 13.
    *   New Pool: $36 - 13 = 23$.
    *   State: Pool=23, Granted=22+13=35.

6.  **Event `r5` arrives (Ask: 16)**
    *   Rule: Grant `min(16, 23)` = 16.
    *   New Pool: $23 - 16 = 7$.
    *   State: Pool=7, Granted=35+16=51.

7.  **Event `r6` arrives (Ask: 20)**
    *   Rule: Grant `min(20, 7)` = 7.
    *   New Pool: $7 - 7 = 0$.
    *   State: Pool=0, Granted=51+7=58.

**Final Calculation:**
*   **Granted Units**: Sum of all successful grants ($4 + 7 + 11 + 13 + 16 + 7$) = 58.
*   **Denied List**: Empty (Pool never hit zero *before* a request arrived).
*   **Pool Left**: 0.
