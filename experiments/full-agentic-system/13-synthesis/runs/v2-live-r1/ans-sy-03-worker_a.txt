### Phase 1 Rule Scan (First Half Only)

Based on the text "night desk sy-03" and the specific rules governing the token pool for tonight's deploy window:

1.  **Arrival/Grant Rule**: Requests land in strict arrival order; grants are partial when the pool cannot cover the full ask; a request arriving at an empty pool is denied and listed by id; a pool that still holds tokens never denies anyone (even if larger than remaining).
2.  **Expiry Rule**: The grant for `r1` expires after request `r2` completes; an expired grant returns half its granted tokens rounded down to the pool; the expiry sentence names exactly one request id (`r1`) so only that one grant ever returns.
