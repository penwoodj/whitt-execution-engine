### Phase 1: RULE SCAN

The following rules govern state changes during the event sequence. Rules are listed in order of priority (higher sources override lower ones) and specific triggers.

1.  **Source Hierarchy Rule**: When a higher-ranked source contradicts a lower-ranked source, the claim becomes `false` based on the higher source's assertion; the lower source is invalidated.
    *   *Triggered by*: Events involving conflicting claims from different sources (e.g., C2).
2.  **Single Source Insufficiency Rule**: A claim resting *only* on hearsay or *only* on the known-buggy dashboard remains `unverified` regardless of content; it does not become true or false automatically.
    *   *Triggered by*: Events where a single low-tier source (hearsay/dashboard) makes an assertion without corroboration (e.g., C4, C5).
3.  **Corroboration Rule**: When multiple sources agree on a claim's content, the claim becomes `true`.
    *   *Triggered by*: Events where distinct sources assert the same fact (e.g., C3).
4.  **Machine Log Authority Rule**: Machine logs are the highest-ranked source; they override signed handoffs and hearsay regarding their specific assertions.
    *   *Triggered by*: Any event involving a machine log assertion that conflicts with others or stands alone against lower sources.
5.  **Signed Handoff Authority Rule**: Signed handoffs rank above hearsay but below machine logs. They validate claims if consistent, or invalidate them if contradicted by higher sources.
    *   *Triggered by*: Any event involving a signed handoff assertion.
6.  **Hearsay Limitation Rule**: Hearsay is the lowest source; it cannot independently verify a claim (resulting in `unverified`) and yields to any other source type.
    *   *Triggered by*: Events relying solely on hearsay or contradicting higher sources.
7.  **Dashboard Bugginess Rule**: The status dashboard is explicitly "KNOWN-BUGGY" and can never carry a claim alone; it results in `unverified` if isolated.
    *   *Triggered by*: Any event relying solely on the dashboard.
