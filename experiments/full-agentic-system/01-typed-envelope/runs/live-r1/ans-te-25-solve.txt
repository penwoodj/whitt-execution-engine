### Phase 1 RULE SCAN
*Listing every rule that changes state during the event sequence:*

1.  **Rule: Load Execution** – Triggered by a "load" request; adds the requested model ID to the active set if capacity allows.
2.  **Rule: Capacity Check & Eviction Trigger** – Triggered when a new load cannot fit within remaining budget; initiates eviction of LRU unpinned models until space is freed or only pinned models remain.
3.  **Rule: Eviction Selection (LRU)** – Triggered during an eviction cycle; selects the Least-Recently-Touched unpinned model for removal.
4.  **Rule: Model Pinned Constraint** – Static rule; prevents pinned models from being selected for eviction under any condition.
5.  **Rule: Deferral Condition** – Triggered if an eviction cycle reduces the active set to only pinned models and space is still insufficient; load request is deferred (state change: `deferrals` count increments, no model loaded).
6.  **Rule: Unload Execution** – Triggered by an "unload" request; removes a specific model from the active set if present.
