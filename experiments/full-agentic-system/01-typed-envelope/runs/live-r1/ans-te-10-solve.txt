### Phase 1 RULE SCAN
*Listing every rule that changes state during the event sequence, including triggers.*

1. **Step Climb Rule**: Triggers on arrival of a new observation; increments rollout percentage by one step (10% per step).
2. **Limit Check Rule**: Evaluates observed error rate against current limit based on step range (Steps 1-5: ≤2.0%, Steps 6-10: ≤1.0%).
3. **Breach Handling Rule (First Breach)**: If Limit Check fails, triggers rollback to previous step; sets observation as spent; tightens remaining limits to 0.8%.
4. **Second Breach Rule**: If a second breach occurs after limit tightening, triggers immediate STOP status; holds current step; no further climbs allowed.
5. **Completion Rule**: If all steps (1-10) are reached without triggering the Second Breach Rule, sets status to DONE.
