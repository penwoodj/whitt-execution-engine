Phase 1 RULE SCAN:
- Arrivals in order (FIFO) rule: Jobs are queued based on arrival time; if core is free, immediate start; if busy, wait.
- Start-minute priority rule (Tie-breaker): Among waiting jobs, the one with the earliest original `start_minute` starts first; resumes outrank fresh jobs only upon a tie in `start_minute`.
- Core occupancy rule: While HIGH runs, no LOW job runs (preemption/stop).
- Checkpoint rule: LOW jobs checkpoint every 2 completed minutes of running time.
- Checkpoint timing exception: A checkpoint lands instantly at the end of the 2nd minute; if an event (like HIGH arrival) happens exactly then, the checkpoint is considered landed and safe before preemption logic applies.
- Preemption/Waste rule: If preempted after a checkpoint, only work past the last checkpoint is wasted. If preempted without completing a checkpoint cycle, all current running time is wasted.
- Resume rule: Upon resumption (after HIGH), the job restarts from immediately after its last saved checkpoint.
