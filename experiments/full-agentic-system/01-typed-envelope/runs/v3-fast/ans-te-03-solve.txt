1. **Arrival Rule**: Triggered by every request ID ($r_1$ through $r_7$) arriving in strict order; attempts to deduct the requested amount from the pool.
2. **Partial Grant Rule**: Triggered when a request arrives and the available pool is less than the ask but greater than zero; grants the full available pool, setting the pool to zero immediately after deduction.
3. **Denial Rule**: Triggered when a request arrives and the pool is exactly zero (empty); denies the request, lists the ID in the denial log, and leaves the pool at zero.
4. **Expiry Return Rule**: Triggered by the completion of Request $r_2$; returns half of the amount *actually granted* to $r_1$ (rounded down) into the pool before processing any subsequent requests.
