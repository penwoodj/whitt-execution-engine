### Phase 1 RULE SCAN
*Listing every rule that changes state during the event sequence, triggered by specific events.*

1. **Rule: Attempt Execution & Costing** – Triggered by each failed attempt (Event 1) and successful attempt (Event 3). Action: Decrease budget by 3 tokens per attempt; increment attempt count.
2. **Rule: Wait Interval Enforcement** – Triggered before every attempt after the first (Events 2, 3). Action: Consume wait time from budget (3s for Event 1->2, 6s for Event 2->3); increment total wait seconds.
3. **Rule: Failure Counting & Retry Logic** – Triggered by failed attempts (Event 1, Event 2). Action: Increment failure counter; if failures < 2, schedule next attempt with doubled wait.
4. **Rule: Success Termination** – Triggered by successful attempt (Event 3). Action: Stop processing further events for this job; final state locked.
5. **Rule: Budget Suppression Check** – Triggered after every cost application (Events 1, 2, 3). Action: If budget < 0, suppress job and double remaining budget limit exactly once; re-check suppression condition immediately after doubling.
