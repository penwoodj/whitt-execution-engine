### Phase 1 RULE SCAN
*Listing rules that change state during the event or claim list, including triggers.*

1. **Rule: Source Hierarchy & Truth Determination**
   - *Trigger:* Every claim arrival (c1, c2, c3, c4).
   - *Logic:* Compare sources based on rank (Machine Log > Signed Handoff > Hearsay/Dashboard). If higher source contradicts lower, status becomes `false`. If only one source exists for a claim:
     - Machine Log -> `true`
     - Signed Handoff -> `true`
     - Hearsay alone -> `unverified`
     - Dashboard alone (Known-Buggy) -> `unverified`

2. **Rule: Claim State Initialization**
   - *Trigger:* Arrival of each claim (c1, c2, c3, c4).
   - *Logic:* Assign initial status based on the highest available source for that specific claim ID according to the hierarchy defined in Rule 1.

*(Note: No expiry, return, refill, or promotion rules are triggered by these specific events as no partial grants or time-based expiries are mentioned in the event list.)*
