**Phase 1 RULE SCAN**
1. Load Rule: A load request attempts to place a model; if it fits in free space, the model is resident and free space decreases by its size.
2. Eviction Rule (Fit): If a load does not fit, evict the least-recently-touched (LRT) **unpinned** models one at a time until enough space exists or only pinned models remain.
3. Deferral Rule: If a load cannot fit even after exhausting all unpinned models (only pinned remain), the request is deferred; no eviction occurs, and the model ID is recorded as deferred.
4. Unload Rule: An unload request frees the specified model's size if it is currently resident; if not resident, it is a no-op.
5. Touch Rule: Every successful load or access moves the touched model to the most-recent position in the recency list.
6. Expiry/Return Rule (Not Triggered): If a grant expires during this stream, it returns half of what was **granted** (the partial amount), rounded down, before the next request is processed.
