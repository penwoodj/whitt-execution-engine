### Phase 1 RULE SCAN
This phase lists every rule that changes state during the event processing, identifying the trigger for each.

1.  **Source Hierarchy Rule**: When a higher source contradicts a lower one, the claim becomes `false` and the lower assertion counts as `false`. Triggered by: Contradiction between sources (e.g., Machine Log vs. Signed Handoff).
2.  **Agreement Rule**: When sources agree on a fact, the claim is `true`. Triggered by: Consistency across multiple valid sources.
3.  **Unverified Status Rule**: A claim resting *only* on hearsay or *only* on the known-buggy dashboard is `unverified` (not false). Triggered by: Single-source claims relying on invalid source types.
4.  **Expiry Return Rule**: When a trigger request completes, an expired grant returns half of what it was **granted** (the partial amount actually given), rounded down, immediately before the next request is processed. Triggered by: Completion of a claim event that references an expired grant.
