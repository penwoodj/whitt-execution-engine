### Phase 1 RULE SCAN
*Listing every rule that changes state during the event sequence, triggered by specific events.*

1. **Load Rule**: Triggered by `load A`. Action: Add model A to resident set if capacity allows; otherwise evict LRU unpinned models until fit or defer.
2. **Eviction Selection Rule**: Triggered by `load D` (due to lack of space). Action: Select least-recently-touched (LRU) *unpinned* model for eviction.
3. **Pinned Model Protection Rule**: Triggered by any potential eviction attempt involving Model C. Action: Prevent eviction of pinned models; if only pinned models remain and no space exists, trigger deferral instead of eviction.
4. **Load Cost Rule**: Triggered by `load A`, `load B`, `load C`, `load D`. Action: Increment internal load counter (state tracking).
5. **Unload Rule**: Triggered by `unload B`. Action: Remove model B from resident set; decrement unload counter (state tracking).

**Event 4: `load D` (Size 7 GB)**
- Check Fit: Current usage 7 + 7 = 14 > 8. Does not fit.
- Eviction Logic: Need to free space. Target deficit = 6 GB (to reach max 8).
- Candidate Pool for Eviction: Unpinned models only.
    - A is unpinned (Size 3).
    - B is unpinned (Size 3).
    - C is pinned (Size 1) -> Protected.
- LRU Selection: Assuming arrival order determines LRU (A arrived first, then B), A is the Least Recently Used among unpinned models.
- Eviction Step 1: Evict A (-3 GB free). Remaining deficit = 3 GB. Resident={B, C}.
- Eviction Step 2: Evict B (-3 GB free). Remaining deficit = 0 GB. Resident={C}.
- Total Space Freed: 6 GB. New Usage: 7 (Model C) + 0 (Evicted) = 7. Available for D: 1 GB? Wait, calculation check.

    - Evict B (3GB): Used becomes 1GB (C). Free becomes 7GB. Now exactly enough for D.
- Action: Evict A, then Evict B. Load D.
- State Update: Resident={C, D}, Usage=8 (1+7), Loads=4, Evictions=2.

**Event 5: `unload B`**
- Check Status: Is B resident? No (evicted in Event 4).
- Action: Unload is a no-op. State remains unchanged.
- State Update: Resident={C, D}, Usage=8, Loads=4, Evictions=2, Deferrals=0.
