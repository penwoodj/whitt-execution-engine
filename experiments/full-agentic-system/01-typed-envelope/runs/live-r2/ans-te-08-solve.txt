### Phase 1 RULE SCAN

Here are the rules that change state during the event list, listed in order of precedence (higher in list applies first), with their triggers:

1.  **Rule: Second Breach Termination** – If a second breach occurs, immediately set `status` to "STOPPED", lock the current step's percentage (`rollout_pct`), and stop further progression.
    *   *Trigger:* The arrival of an observation that breaches its specific limit (the 2nd breach in this sequence).

2.  **Rule: Limit Tightening** – After any successful rollback, update the error rate limits for all *remaining* steps to 0.8 percent. These tightened limits apply to future observations but do not retroactively invalidate the current observation if it was already observed within the previous (looser) limit before the rollback logic finalized the state transition.
    *   *Trigger:* The completion of a rollback event (Step $N$ breaches $\to$ Rollback $\to$ Limit Update).

3.  **Rule: Breach and Rollback** – If an observation's error rate exceeds its current step's limit:
    *   Consume the observation (mark it spent/failed).
    *   Do not increment the stage count for this failed step.
    *   Set `rollout_pct` back to the previous valid step's percentage (or 0 if no prior steps existed, though here we climb in 10% steps so it goes $N-1 \times 10$).
    *   Trigger Rule #2 (Limit Tightening) for future steps.
    *   *Trigger:* An observation arriving with an error rate > current limit.

4.  **Rule: Stage Completion and Climb** – If an observation's error rate is within the current step's limit:
    *   Increment the stage counter (`stages_done`).
    *   Update `rollout_pct` to $10 \times$ `stages_done`.
    *   Mark this stage as completed.
    *   Prepare for the next observation (next step).
    *   *Trigger:* An observation arriving with an error rate $\le$ current limit.

5.  **Rule: Initial State & Step Assignment** – The rollout starts at Stage 0 / 0%. Each new observation attempts to complete the "current" stage defined by the number of clean observations achieved so far.
    *   *Trigger:* The arrival of the first observation in a sequence.
