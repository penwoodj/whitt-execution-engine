### Phase 1 RULE SCAN
*Listing every rule that changes state during the event sequence (Load A, Load C, Load D, Unload D), including expiry/return logic implied by the "deferred" status.*

1. **Rule: Model Loading** – Triggered by `load X` events; adds model to resident set if capacity allows.
2. **Rule: Capacity Check & Eviction** – Triggered by `load X` when insufficient space; evicts Least-Recently-Touched (LRU) unpinned models until fit or only pinned remain.
3. **Rule: Pinned Model Protection** – Triggered implicitly during eviction checks; prevents eviction of pinned models (Model B).
4. **Rule: Load Failure/Deferral** – Triggered if capacity cannot be met even after exhausting all evictable unpinned models; model moves to deferred list, no state change for resident set.
5. **Rule: Unload Operation** – Triggered by `unload X`; removes model from resident set and frees capacity (no-op if not resident).
