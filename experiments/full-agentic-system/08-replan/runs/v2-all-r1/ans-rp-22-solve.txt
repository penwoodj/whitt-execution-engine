**Phase 1 RULE SCAN**
1. **Load Rule**: A load request attempts to place a model of specific size into the pool; if it fits (pool_size >= requested_size), it succeeds immediately.
2. **Eviction Rule**: If a load does not fit, evict the Least-Recently-Touched (LRT) *unpinned* models one at a time until enough space exists or only pinned models remain. Each eviction counts toward the total.
3. **Deferral Rule**: If after exhausting all unpinned models there is still insufficient space for the requested load, and only pinned models remain, defer the load (no evictions performed).
4. **Touch Rule**: Every successful load or partial fit updates the recency of the involved model(s) to Most-Recently-Touched.
5. **Unload Rule**: An unload request frees the specified size from the pool immediately; if the model is not resident, it is a no-op.
