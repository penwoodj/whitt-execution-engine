2.  **Budget Check Rule**: Triggers after each Arrival rule application. Compares current `total_spend` against `budget`. If `total_spend > budget`, triggers the doubling mechanism.
3.  **Doubling Rule**: Triggers only if Budget Check Rule fires (spend exceeds budget). Doubles the `budget` value exactly once. Sets a flag that the budget has been doubled for this session.
