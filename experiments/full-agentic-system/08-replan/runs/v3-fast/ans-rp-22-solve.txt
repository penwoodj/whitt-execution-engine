**Phase 1 RULE SCAN**
1. **Load Rule**: A load request attempts to place a model of specific size into the pool; if it fits (size <= free space), it succeeds immediately.
2. **Eviction Rule**: If a load does not fit, evict the Least-Recently-Touched (LRT) *unpinned* models one at a time until enough space exists or only pinned models remain. Each eviction increments the `evictions` counter.
3. **Deferral Rule**: If after exhausting all unpinned models the load still cannot fit (only pinned models remain), the load is deferred; no evictions occur for this step, and the load ID is recorded in `deferred`.
4. **Touch/Recency Rule**: Every successful load or eviction of a model updates its recency to "most recent". The LRT model is determined by scanning unpinned models from oldest (least touched) to newest.
5. **Unload Rule**: An unload request frees the specified size immediately if the model is resident; it is a no-op if not resident.

   - State: Resident {A}, Free 7.
