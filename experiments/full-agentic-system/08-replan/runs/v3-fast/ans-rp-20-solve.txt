**Phase 1 RULE SCAN**
1. **Load Rule**: A load request attempts to place a model of specific size into the pool; if it fits (including room for future requests implicitly handled by "fits"), it loads immediately. If it cannot fit, evictions occur first.
2. **Eviction Rule**: When a load cannot fit, the system evicts the Least-Recently-Touched (LRT) *unpinned* models one at a time until enough space is available. Each eviction counts toward the total.
3. **Deferral Rule**: If a load still cannot fit after all unpinned models are evicted (i.e., only pinned models remain), the load is deferred. No further evictions occur for this specific load. The load ID is recorded as deferred.
4. **Touch/Recency Rule**: Every successful load or eviction of a model updates its recency to "Most-Recently-Touched". Unloaded models are removed from the resident set.
5. **Unload Rule**: An unload request frees the specified amount of space immediately, regardless of current residency (if not resident, it is a no-op).
