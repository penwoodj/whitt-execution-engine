**Phase 1 RULE SCAN**
1. **Load Rule**: A load request attempts to place a model of specific size into the pool; if it fits (including room for future growth), it succeeds immediately without eviction.
2. **Eviction Rule**: If a load cannot fit, the system evicts one unpinned, least-recently-touched (LRT) resident at a time until enough space is free; each successful removal counts as an eviction.
3. **Deferral Rule**: If after exhausting all unpinned LRT residents there is still insufficient space (because only pinned models remain), the load is deferred (no evictions counted for this specific step, but previous evictions count).
4. **Touch Rule**: Every time a model is loaded or accessed during an eviction sequence, it becomes the most-recently-touched resident.
5. **Unload Rule**: An unload request frees the specified amount of space immediately; if the model is not currently resident, this is a no-op.
