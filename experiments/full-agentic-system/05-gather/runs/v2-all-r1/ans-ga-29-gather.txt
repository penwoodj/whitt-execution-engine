- load C (3 GB)
- load D (4 GB)
- unload D (4 GB)
- model C is pinned and never evicted
- resident sizes: A1 B2 C3 D4 GB respectively
- loads cost 30s, unloads 10s
- a load that cannot fit evicts as many LRU unpinned models as needed
- if only pinned models remain and it still does not fit it defers
- every eviction actually performed counts in the evictions total even when the load ends up deferred
- an unload for a model no longer resident is a no-op
