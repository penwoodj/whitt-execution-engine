Based on the task description and "orientation" story provided, here are the rules that change state during an event or claim list:

1.  **Load Rule**: A request to load a model loads it if there is sufficient free space in the pool.
2.  **Eviction Rule (Fit)**: If a load cannot fit, evict the least-recently-touched (LRT) *unpinned* models one at a time until enough space exists for the requested model.
3.  **Deferral Rule**: If a load cannot fit and only *pinned* models remain in the pool (or no unpinned models exist to evict), defer the load. No eviction occurs; record the ID as deferred.
4.  **Touch Rule**: Every successful load or partial access moves the model to the most-recent position in the recency list.
5.  **Unload Rule**: A request to unload a resident model frees its size from the pool immediately (no-op if not resident).
