**Phase 1 RULE SCAN**
1. Load Rule: If requested stream fits in current free space, load the model; otherwise proceed to eviction logic.
2. Eviction Logic (Fit): If a load cannot fit, evict least-recently-touched (LRT) **unpinned** models one at a time until it fits or only pinned models remain.
3. Deferral Rule: If a load still does not fit after exhausting all unpinned models (only pinned remain), defer the load; no eviction occurs.
4. Touch Rule: Every successful load or partial load moves the model to Most-Recent position in recency list.
5. Unload Rule: Freeing a resident model adds its size to free space; freeing a non-resident model is a no-op.
6. Expiry Return Rule (Triggered by Load): Upon completion of a load event, if that specific grant was previously marked expired/partial, return half the **granted** amount (rounded down) immediately before processing subsequent events.
