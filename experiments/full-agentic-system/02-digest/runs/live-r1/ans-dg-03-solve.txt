### Phase 1 RULE SCAN
*Listing every rule that changes state during the event or claim list, including triggers.*

1. **Arrival Rule**: Request `rN` arrives with an ask of `X` tokens; if pool >= X, grant X and subtract from pool; if pool < X, grant remaining pool (partial) and set pool to 0.
2. **Denial Rule**: If a request arrives at an empty pool (pool == 0), the request is denied, its ID is recorded in the denial list, and no tokens are added back or removed from the pool.
3. **Expiry Rule**: The grant for `r1` expires immediately after request `r2` completes; upon expiry, half of the *granted* amount (rounded down) returns to the pool.
4. **State Persistence Rule**: The state (pool balance and denial list) is updated sequentially after each event in strict arrival order; no events are skipped or reordered.
