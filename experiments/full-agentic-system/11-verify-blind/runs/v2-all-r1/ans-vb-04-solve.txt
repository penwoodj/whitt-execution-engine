### Phase 1 RULE SCAN
*Listing every rule that changes state during the event or claim list.*

1.  **Arrival Rule**: Requests land in strict arrival order; each asks for a fixed number of tokens.
2.  **Grant Rule (Full)**: If the pool covers the full ask, grant the full amount and subtract from the pool.
3.  **Grant Rule (Partial)**: If the pool cannot cover the full ask, grant whatever remains in the pool (pool drops to zero), and the request is still considered "granted" (not denied).
4.  **Denial Rule**: A request arriving at an empty pool (exactly zero) is denied and listed by ID; a partial grant never triggers denial.
5.  **Expiry Trigger Rule**: The grant for `r2` expires after request `r3` completes.
6.  **Return Amount Rule**: An expired grant returns half of its *granted* tokens (rounded down), not the asked amount.
7.  **Timing Rule**: The expiry return happens immediately before the next request is processed (specifically, right before `r4` arrives).
