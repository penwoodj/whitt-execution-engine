### Phase 1 RULE SCAN
*Listing every rule that changes state during the event or claim list.*

1.  **Arrival Rule**: Requests land in strict arrival order; each asks for a fixed number of tokens.
2.  **Grant Rule (Full)**: If the pool covers the full ask, grant the full amount and subtract from the pool.
3.  **Grant Rule (Partial)**: If the pool cannot cover the full ask but has tokens, grant what is there (partial) and drain the pool to zero. This remains a "granted" request, not denied.
4.  **Denial Rule**: A request arriving at an empty pool (exactly zero) is denied and listed by ID.
5.  **Expiry Trigger Rule**: The grant for `r2` expires after request `r3` completes.
6.  **Return Amount Rule**: An expired grant returns half of its *granted* tokens (rounded down), never half of the ask, and only that specific grant returns.
7.  **Timing Rule**: The expiry return happens immediately before the next request is processed (after the trigger completes).
