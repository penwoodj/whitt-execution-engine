### Phase 1 RULE SCAN
The following rules govern state changes during the event sequence. Each rule is listed on one line with its trigger condition.

1. **Arrival Rule**: Triggered by every request ID arriving in strict order; updates the pool state based on the ask amount and current balance (grant full, partial, or deny).
2. **Expiry Rule**: Triggered immediately after a specific named request completes (as defined by the expiry sentence); returns half of the tokens *actually granted* to that request (rounded down) to the pool before the next event processes.
