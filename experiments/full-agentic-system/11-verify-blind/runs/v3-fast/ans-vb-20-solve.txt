**Phase 1 RULE SCAN**
1. **Load Rule**: A load request attempts to place a model of specific size into the pool; if it fits (total used + new size <= capacity), it succeeds immediately.
2. **Eviction Rule**: If a load does not fit, evict the Least-Recently-Touched (LRT) *unpinned* models one by one until there is room for the requested model. Each eviction increments the eviction counter and updates recency.
3. **Deferral Rule**: If a load cannot fit even after evicting all unpinned models (only pinned models remain), the load is deferred; no further evictions occur, and the load ID is recorded as deferred.
4. **Touch/Recency Rule**: Every successful load or eviction of a model updates that model's recency to "most recent". Unloaded models are removed from the pool.
5. **Capacity Constraint**: The total size of resident models must not exceed the card capacity (8 GB).
