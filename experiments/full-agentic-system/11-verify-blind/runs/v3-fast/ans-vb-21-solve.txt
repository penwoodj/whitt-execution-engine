**Phase 1 RULE SCAN**
1. **Load Rule**: A load request attempts to add a model of specified size; if it fits in remaining free space, the model is loaded and its ID is added to the resident set (moving it to most-recent).
2. **Eviction Rule**: If a load does not fit, the system evicts one unpinned model at a time, specifically choosing the least-recently-touched (LRU) among all *unpinned* models, until enough space is freed for the new load. Each eviction increments the eviction counter.
3. **Pinning Rule**: Model B is pinned and can never be evicted. Unload operations on non-resident models are no-ops.
4. **Deferral Rule**: If a load cannot fit even after all unpinned (LRU) models have been evicted, the load is deferred. The model is not loaded, no further evictions occur for this specific request, and the load ID is recorded as deferred.
5. **Recency Update Rule**: Every time a model is loaded or touched during an eviction sequence, it moves to the most-recent position in the resident set.
