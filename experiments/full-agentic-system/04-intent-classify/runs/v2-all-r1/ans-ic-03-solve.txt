### Phase 1 RULE SCAN
This phase lists every rule that changes state during the event sequence, identifying the specific trigger for each.

1.  **Grant Rule**: Triggers on request arrival; grants `min(ask, pool)`, reducing the pool by the granted amount.
2.  **Denial Rule**: Triggers only if a request arrives when the pool is exactly zero; denies the request and leaves the pool at zero.
3.  **Expiry Return Rule**: Triggers upon completion of the request named in the expiry sentence (Request ID); returns `floor(granted_amount / 2)` to the pool immediately before processing the next arrival.
