# 07-solve — Research & Reasoning

## Why this atom exists
Every composite experiment needs a denominator. Solve establishes what
a bare narrow-scope CoT call does at each difficulty level, so plan lift,
digest equivalence, router savings are all measured against SOMETHING.

## Sources

  the cot style prefix is frozen from v14c lessons (never reword).
- **Sample-More-Reflect-Less (arXiv 2607.28576):** cost-matched sampling
  beats reflection at small scale → our depth-1 wait retry is the cheap
  resample rung, not a self-reflect loop.

  solve baseline + each atom's delta IS the harness decomposition.

- **EMNLP 2025 arithmetic ICL:** FORMAT CONSISTENCY of examples beats their
  arithmetic correctness — shared scaffold is identical across all 48
  cases so format consistency is controlled.
- **E1 bounded budget:** wait stage capped (400 tokens v1) — budget forcing

## Reasoning chain
1. Difficulty ramp via idx (params shift modularly) — monotone decline
   expected; non-monotonicity = case-set bug, catch before any atom claim.
2. Bucket design [6,2] fixes the spoof machinery target; live deviation
   from 75/25 beyond 15pp flags drift (H3's tripwire).
3. Failure taxonomy (FORMAT/CONTENT/LEAK) at each depth becomes the
   shared vocabulary for 01/02/11 analyses.

## What would change our mind

EVERY other experiment's interpretation (which is the point).
