### Phase 1 RULE SCAN
This phase lists every rule in the task that changes state during the event sequence (the "flaky upstream" scenario), identifying the trigger for each.

1.  **Per-Attempt Cost Rule**: Triggers on every attempt (failed or successful). Adds `2` tokens to spend.
2.  **Wait Second Cost Rule**: Triggers after a failed attempt before the next retry. Adds `N` seconds (where N is the current wait time) to spend.
3.  **Budget Accumulation Rule**: Triggers on every cost event (attempt or wait). Updates total `spend`.
4.  **Suppression Threshold Rule**: Triggers when `spend > budget`. Sets initial state of `suppressed` to true and flags the "doubling" condition.
5.  **Budget Doubling Rule**: Triggers if suppression is active (`spend > budget`). Doubles the `budget` value exactly once.
6.  **Re-Check Suppression Rule**: Triggers after doubling. Re-evaluates `suppressed` based on new doubled budget vs original spend. Sets final `suppressed` state (false if under, true if over).
7.  **Final Budget After Calculation Rule**: Triggers at the end of the sequence. Computes `budget_after = final_budget - total_spend`.
