Phase 1 RULE SCAN:

- On request arrival (timestamp), if bucket capacity is exceeded, reject the request. Trigger: every request event.
- If request weight > 0, consume tokens equal to request weight from bucket; if insufficient tokens, partially serve or reject based on available tokens. Trigger: every request with positive weight.
- Bucket refill occurs at a rate of 10 tokens per second (i.e., 10 tokens added every second), applied continuously and in integer steps. Trigger: every second boundary (every 1s interval).
- At each timestamp, if the bucket has fewer than 1 token, no refill is applied until next second boundary; refill only occurs at full-second boundaries. Trigger: every second boundary.
- If a request has weight zero, it is accepted immediately with no token consumption and no state change. Trigger: any request with weight = 0.
- For requests with fractional millisecond weights, round down to nearest integer (floor) before processing. Trigger: all requests with non-integer weights.
- A timestamp that is out of order by one second (i.e., later than the previous event) is treated as a duplicate or invalid; such events are rejected and logged. Trigger: any request with timestamp > previous request + 1s.
- If bucket state reaches zero, no refill occurs until next full second boundary. Trigger: every second boundary.
- On burst arrival (defined by two consecutive high-weight requests within 0.5 seconds), trigger a temporary override: allow up to 20% more token consumption for the first three requests in the burst. Trigger: any burst event (two high-weight requests within 0.5s).
- If bucket state is negative after refill, set it to zero; no negative states allowed. Trigger: every second boundary.
- On request rejection due to insufficient tokens, record rejection spike and log timestamp. Trigger: every request with insufficient tokens.
- When a refill occurs, only add 10 tokens per second (no partial refills). Trigger: every full-second boundary.
- If bucket capacity is reached during refill, no overflow; cap at 100. Trigger: every refill event.
