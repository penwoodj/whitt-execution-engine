# Forecast Run - Self-Contained, Deterministic Pipeline

This directory contains a complete, end-to-end forecasting pipeline that runs entirely in-memory with standard Python or bash. All outputs are deterministic, reproducible, and logged step-by-step.

## Files
- `raw_data.csv` – 12 months of monthly traffic per service (6 services)
- `rules.md` – all rules defined with thresholds and rationale
- `forecast.json` – final forecast output
- `forecast.md` – human-readable report with tables, method details
- `logs/` – stage-by-stage logs (one line per step)
- `verify.sh` – standalone verifier script that recomputes key values from raw input
- `README.md` – this document
