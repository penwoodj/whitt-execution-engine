(1) FIRST HALF SCOPE — rules and event lines belonging to the first half of the task (steps 1–4, inclusive):

- Step 1: Five-way delta classification using hash where available; if no hash, use size and mtime.  
  Rule: If a path exists in snapshot A but not in B → classify as "added".  
  Rule: If a path exists in snapshot B but not in A → classify as "removed".  
  Rule: If a path exists in both with same size and mtime, and hash matches → classify as "same-size-rewritten" (only if hash is present).  
  Rule: If a path exists in both with same hash but different size → classify as "grown" or "shrunk" based on size comparison.  
  Rule: If a path exists in both with same size and mtime, but hash differs → classify as "rewritten".  
  Rule: If a path exists in both with same size and hash, but mtime differs → classify as "same-size-invariant", not in five-way delta (this is handled later).  
  Threshold for grown/shrunk: size difference ≥1 byte.
