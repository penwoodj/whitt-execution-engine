Phase 1 RULE SCAN:

- Elevator window expiry rule: triggers when an elevator slot ends (e.g., at 14:00), revokes all pending carries and shuttles scheduled after that time.  
- Desk must go during elevator window rule: triggers when the desk item is identified; it requires a carry during the elevator window only, and blocks any stairwell use for that item.  
- Fragile box stacking restriction rule: triggers when a fragile box is encountered in inventory; prohibits stacking of any three boxes on top of one another.  
- Item duplication detection rule: triggers when two entries are found with same physical ID (e.g., "desk" and "office desk"); flags both rows for review, marks them as duplicate and merges into one entry.  
- Heavy item mover pairing rule: triggers when a heavy item is scheduled; requires both movers to be assigned to that carry event.  
- Refill rule: triggers if any carry or shuttle exceeds 2 hours of estimated time; automatically reassigns to next available slot with a 30-minute buffer and logs the overflow.  
- Fallback rule: triggers when no elevator window is available for an item requiring one (e.g., desk); falls back to stairwell, but only if the item is not heavy or exceeds size limits.  
- Source-ranking rule: triggers during schedule generation; ranks carries by estimated time first, then by floor origin, ensuring lower-floor items are prioritized unless elevator constraint overrides.  

Event/Claim Triggers:
- Elevator window expiry → at 14:00 (end of slot)  
- Desk must go during elevator window → when desk item is identified in inventory  
- Fragile box stacking restriction → when fragile box is listed in inventory

- Heavy item mover pairing → when heavy item is scheduled for carry  
- Refill rule → when estimated time > 2 hours  
- Fallback rule → when no elevator window available and item requires one  
- Source-ranking rule → during initial schedule generation
