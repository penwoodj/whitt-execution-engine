## Rules Applied (in rules.md)

   - Threshold: ≥30 size, and no cleanup command after → flag.  
2. **Duplicated data adds**: If same file is created in one layer and copied to another with no deletion → flag.  
   - Threshold: Same content, different paths → flag.  
3. **Add-then-remove pairs**: Must have a layer that creates a file or directory, followed by a layer that deletes it.  
   - Threshold: File exists before, deleted after (by name or path).
