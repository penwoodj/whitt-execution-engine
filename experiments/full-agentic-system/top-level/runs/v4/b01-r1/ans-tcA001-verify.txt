### 1. Directory Structure & Rules (`rules.md`)

Create this file first to define the contract for the pipeline.

```markdown
# Warehouse Pipeline Rules (rules.md)

## Environment
- Base Path: /tmp/opencode/warehouse-test
- No network access, no external packages (standard library python3 only).
- Non-interactive execution (no prompts, no read -p).
- Loud failures: All scripts exit with non-zero code on error.
- Idempotent/Stable Overwrite: Running a stage twice safely overwrites output files; no cleanup of intermediate temp files required as outputs are atomic writes.

## Data Generation (fixtures)
- 200 JSON record files split into 4 subfolders: `inbound`, `outbound`, `quarantined`, `archived`.
- Fields: part_id, part_name, category, quantity_on_hand, unit_cost, warehouse_location, last_inspected, status.
- Realism constraints:
  - Unique part_ids mostly, but intentional duplicates (same ID twice) and malformed files (missing comma, trailing brace).
  - Categories: fastener, electrical, housing, consumable, sensor.
  - Statuses: ok, needs_review, defective.

## Pipeline Stages

### Stage 1: Scan (`scan.py`)
- Scans all 4 folders.
- Validates JSON syntax and required fields.
- Output: `manifest.json` (all valid records).
- Rejects: `rejects.log` (filename + reason for malformed/invalid files).

### Stage 2: Dedupe (`dedupe.py`)
- Logic:
  - Exact same part_id twice -> Keep newest by file modification time. Log loser to `duplicate_losers.log`.
  - Same part_name in same category with differing quantities -> Flag as potential duplicate to `review_candidates.json` (do not auto-decide).
- Output: `clean_manifest.json` (deduplicated valid records).

### Stage 3: Report (`report.py`)
- Computes metrics from `clean_manifest.json`:
  - Total distinct parts.
  - Total inventory value (sum of qty * cost).
  - Per-category counts and values.
  - Defective rate (%).
  - Count needing review.
  - Top 5 most expensive single line items.
  - Zone breakdown (value by warehouse zone).
- Outputs: `warehouse-report.md` (human readable) and `warehouse-report.json` (machine copy).
- Constraint: Numbers must match exactly between MD and JSON.

### Stage 4: Verify (`verify.py`)
- Recomputes all metrics independently from raw fixture files (ignoring pipeline outputs).
- Compares computed values against `warehouse-report.md` and `warehouse-report.json`.
- Checks file counts: distinct + rejects + duplicate_losers == total input files.
- Exits non-zero on any mismatch or count discrepancy.

## Execution Flow
1. Generate fixtures (run script once).
2. Run pipeline stages sequentially.
3. Run verifier.
4. If verifier passes, run timing test (3 runs) and efficiency check.
```

```python
import os

import random

BASE_PATH = "/tmp/opencode/warehouse-test"
SUBFOLDERS = ["inbound", "outbound", "quarantined", "archived"]
CATEGORIES = ["fastener", "electrical", "housing", "consumable", "sensor"]
STATUSES = ["ok", "needs_review", "defective"]

# Helper to generate random date in last year
def rand_date():
    base = datetime(2023, 1, 1)
    delta = timedelta(days=random.randint(0, 365))
    return (base + delta).strftime("%Y-%m-%d")

# Generate a list of unique part IDs and names to reuse
part_ids_pool = [f"PTM-{str(i).zfill(5)}" for i in range(1, 201)]
names_pool = ["Bracket-Alpha", "Cable-HV", "Sensor-Light", "Nut-M6", "Housing-IP67", 
              "Fuse-Slow", "Switch-Tactile", "Connector-Female", "Resistor-1k", "Capacitor-Elec"]

def generate_record(idx):
    # Mostly unique, but force some duplicates and malformed files based on index
    is_malformed = (idx % 50 == 49) # Every 50th file is malformed
    
    if is_malformed:
        pid = random.choice(part_ids_pool)
        name = random.choice(names_pool)
        cat = random.choice(CATEGORIES)
        qty = random.randint(0, 100)
        cost = round(random.uniform(1.00, 500.00), 2)
        loc = f"{random.choice(['A','B','C','D','E'])}{random.randint(10,99)}"
        date = rand_date()
        status = random.choice(STATUSES)
        
        # Create malformed JSON
        if idx % 50 == 49:
            if idx % 100 == 49:
                return f'{{"part_id": "{pid}", "part_name": "{name}", "category": "{cat}", "quantity_on_hand": {qty}, "unit_cost": {cost}, "warehouse_location": "{loc}", "last_inspected": "{date}", "status": "{status}"}}' # Missing comma before status
            else:
                return f'{{"part_id": "{pid}", "part_name": "{name}", "category": "{cat}", "quantity_on_hand": {qty}, "unit_cost": {cost}, "warehouse_location": "{loc}", "last_inspected": "{date}"}}' # Missing status field
        
        return json.dumps({
            "part_id": pid,
            "part_name": name,
            "category": cat,
            "quantity_on_hand": qty,
            "unit_cost": cost,
            "warehouse_location": loc,
            "last_inspected": date,
            "status": status
        })

def main():
    os.makedirs(BASE_PATH)
    for sub in SUBFOLDERS:
        path = os.path.join(BASE_PATH, sub)
        os.makedirs(path)
        
        # Generate 50 files per folder (200 total)
        for i in range(50):
            content = generate_record(i + (SUBFOLDERS.index(sub) * 50))
            filename = f"record_{i:03d}.json"
            filepath = os.path.join(path, filename)
            
            # Add slight delay to modification times for dedupe logic testing
            with open(filepath, 'w') as f:
                f.write(content)
            
            # Manipulate mtime slightly for specific files to test "newest wins"
            if i == 10 and sub == "inbound":
                os.utime(filepath, (datetime.now().timestamp() - 3600, datetime.now().timestamp() - 3600))
```

### 3. Pipeline Stage 1: Scan (`scan.py`)

Scans folders, validates JSON, outputs manifest and rejects log.

```python
#!/usr/bin/env python3
import os
import json
import sys

BASE_PATH = "/tmp/opencode/warehouse-test"
SUBFOLDERS = ["inbound", "outbound", "quarantined", "archived"]
MANIFEST_FILE = os.path.join(BASE_PATH, "manifest.json")
REJECTS_LOG = os.path.join(BASE_PATH, "rejects.log")

def main():
    valid_records = []
    rejects = []
    
    for sub in SUBFOLDERS:
        path = os.path.join(BASE_PATH, sub)
        if not os.path.isdir(path):
            print(f"Error: Directory {path} not found", file=sys.stderr)
            sys.exit(1)
            
        for filename in sorted(os.listdir(path)):
            filepath = os.path.join(path, filename)
            try:
                with open(filepath, 'r') as f:
                    content = f.read()
                
                # Try to parse JSON
                data = json.loads(content)
                
                # Check required fields
                required = ["part_id", "part_name", "category", "quantity_on_hand", 
                            "unit_cost", "warehouse_location", "last_inspected", "status"]
                missing = [field for field in required if field not in data]
                
                if missing:
                    rejects.append(f"{filename}: Missing fields {missing}")
                    continue
                
                # Validate types roughly
                if not isinstance(data["quantity_on_hand"], (int, float)) or data["quantity_on_hand"] < 0:
                     rejects.append(f"{filename}: Invalid quantity")
                     continue
                    
                valid_records.append(data)
                
            except json.JSONDecodeError as e:
                rejects.append(f"{filename}: JSON Syntax Error - {str(e)}")
            except Exception as e:
                rejects.append(f"{filename}: Unexpected Error - {str(e)}")

    # Write Manifest (overwrite safe)
    with open(MANIFEST_FILE, 'w') as f:
        json.dump(valid_records, f, indent=2)
    
    # Write Rejects Log
    with open(REJECTS_LOG, 'w') as f:
        for r in rejects:
            f.write(r + "\n")
            
    print(f"Scan Complete. Valid: {len(valid_records)}, Rejected: {len(rejects)}")

if __name__ == "__main__":
    main()
```
