```markdown
# Trace Analysis Rules (rules.md)

## Data Handling
- **Self-Time**: $ST = D - \sum(CD)$. If result < 0, flag as "ILLEGAL_OVERLAP". Do not drop.
- **Precision**: No rounding for intermediate calculations. Final display: 6 decimal places for time, 4 for percentages.
- **Anomalies**: Orphan spans and negative durations are recorded in a separate `anomalies.json`.

## Output Consistency
- **Human/Machine**: `waterfall.md` contains formatted tables. `waterfall.json` contains raw floats. Values must match mathematically; visual formatting differences allowed only if explicitly noted.
- **Denominators**: All percentages include the total sum in parentheses (e.g., "12.5% (of 400ms)").

## Execution Policy
- **Idempotent**: Scripts clean inputs or regenerate them deterministically. Running twice yields identical outputs.
- **Fail Loud**: Non-zero exit code on any data integrity check failure.
- **No Prompts**: Fully non-interactive.

## File Structure
- `inputs/`: Raw trace JSONs (generated).
- `outputs/`: Human tables, machine JSON, anomaly reports.
- `logs/`: One-line stage logs with timestamps.
- `scripts/`: Python logic.
- `verify.sh`: Independent recomputation script.
```
