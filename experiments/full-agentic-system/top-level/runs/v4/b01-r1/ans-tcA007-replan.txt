# Alert Storm Dedup Pipeline

## Structure
- `raw/`: Contains synthetic input data (alerts.csv).
- `rules/`: Logic definitions.
    - `rules.md`: Thresholds and grouping rules.
- `scripts/`: Python 3 standard library only.
    - `01_parse.py`: Timestamp normalization & sorting.
    - `02_group.py`: Incident creation & merging.
    - `03_noise.py`: Noise maker detection (>10 alerts).
    - `04_verify.py`: Conservation check (input vs output).
- `outputs/`: Final artifacts.
    - `storm.json`: Aggregated incidents.
    - `edge_cases.md`: Disposition of anomalies.
    - `logs.txt`: Stage execution logs.

## Rules Summary
1. **Grouping**: Alerts with same `template` and time diff < 5 mins merge into one incident.
2. **Noise Maker**: Template count > 10 within an incident triggers flag.
3. **Timestamps**: Mixed
