## Rules & Thresholds (From `rules.md`)

```markdown
# Trace Analysis Pipeline Rules

## Data Processing
- Self-time = span.duration - sum(children.duration) for all direct children
- Negative durations → corrected to 0.0ms and logged
- Illegal parent overlap (end > parent.end) → flagged but not excluded
- Orphan traces → processed as single-span traces

## Output Standards
- Percentages always include denominator: "18.42% of total time"
- No rounding below 2 decimal places unless <0.01ms
- All timestamps in microseconds (us) for precision

## Error Handling
- Exit code 0 only if all stages complete successfully
- Non-zero exit codes with descriptive messages on failure
- Anomalies logged to stderr and included in output JSON

## Verification
- All outputs recomputable from raw trace files
- Independent checker script validates invariants mechanically
```
