- Rule: If a product record has missing `price`, reject it with error "missing price" and log in load-report.md under "field_missing_price". Triggered by: any row without 'price'.  
- Rule: If a product record contains a price string with currency symbol (e.g., "$10.99"), strip the symbol and convert to number; if invalid, reject with error "invalid price format" and log in load-report.md under "invalid_price_format". Triggered by: any row where price is a string containing a currency symbol.  
- Rule: If a product record contains a price string without a valid numeric value (e.g., "abc"), reject it with error "non-numeric price" and log in load-report.md under "non_numeric_price". Triggered by: any row where price is non-numeric after stripping.

- Rule: If a product record has duplicate entries (same name + price), flag as duplicate and add to quarantine list labeled "duplicates", logging in load-report.md under "duplicates". Triggered by: any row with identical name and price values across the array.
