## Directory Snapshot Delta Analysis Pipeline

This pipeline computes a five-way delta between two directory snapshots (snapshot1 and snapshot2), handles edge cases including renames, case sensitivity, mtime liars, and hashless files. All logic is deterministic, self-contained, and reproducible without external dependencies or network calls.

The output includes:
- `delta.json`: machine-readable delta report
- `delta.md`: human-readable summary with tables
- `logs/` directory: per-stage logs (one line each)
- `rules.md`: all rules with thresholds and reasoning
- `decisions.md`: design choices, defaults, and data contradictions
- `checker.py`: independent verifier that re-computes every stage

All stages run twice. First run validates correctness; second run detects state bugs.
