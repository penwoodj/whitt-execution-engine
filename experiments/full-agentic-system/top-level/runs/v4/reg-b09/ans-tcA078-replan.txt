# Rules for Dependency Cycle Detection Pipeline

1. **Drop self-dependencies**: Remove any edge where source == target.  
   - Trigger: Any row with `source == target` in input.
   - Reason: Self-loops are logically invalid; a package cannot depend on itself.

2. **Deduplicate edges**: Merge identical edges (same source, same target, same version constraint).  
   - Identical = same source, same target, and same version constraint string (case-insensitive, whitespace-trimmed).
