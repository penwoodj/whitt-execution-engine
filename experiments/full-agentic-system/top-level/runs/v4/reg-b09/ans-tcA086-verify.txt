deliverables:  
- weather.md: human-readable table of daily temperature data, with gap flags and freeze events per station, raw vs filled.  
- filled.csv: same as original but with interpolated values marked by method (time, station-correlation), with metadata columns for gap status and interpolation source.  
- gaps.json: JSON object listing per-station missing durations in days, total missing percentage, distribution of gap lengths, and outlier flags.  
- rules.md: justification for each rule used, including thresholds (e.g., "gap < 3 days → time-interpolate", "gap ≥ 3 days → station-correlation"), with reasoning and data basis.  
- decisions.txt: one line per data issue type, e.g., "Station A: Celsius → convert to Fahrenheit; Station B: F → convert to C; Outlier at day 150: value -273.15 → flagged as sensor lie and replaced with NaN".  

data handling:  
- All timestamps are parsed as ISO 8601, converted to day-of-year (DOY) for consistency across non-leap year (366 days).  
- Temperature units: all converted to Celsius; conversion formula applied consistently.  
- Physical outlier detection: any temperature < -273.15°C is flagged and treated as sensor error.  
- Gap census: per-station, total missing days, duration distribution (bins of 1–2, 3–4, etc.), percentage missing = (missing_days / 366) × 100%.  
- Interpolation policy:  
  - Gaps < 3 days → time-interpolate using linear regression on adjacent valid days.  
  - Gaps ≥ 3 days → station-correlation: use average of neighboring stations’ values at same DOY, weighted by proximity (distance in day-of-year).  
- Freeze event count: defined as days where temperature ≤ 0°C; computed separately on raw and filled data. Delta = (filled freeze events) - (raw freeze events), with gap status affecting validity.  
- All outputs are deterministic: seeded random number generator (if used, e.g., for outlier sampling) set to 42; all file I/O timestamped.  

verification:  
- verify_pipeline.py runs independently and compares outputs against expected values. It checks:  
  - Total missing days per station matches gap census.  
  - Interpolation method is correctly applied (e.g., no time-interpolated value in a gap ≥3 days).  
  - Freeze event delta is consistent with data quality flags.  
- Runs twice: first run produces outputs; second run reprocesses and compares. If any output differs, error message includes file path and line number.
