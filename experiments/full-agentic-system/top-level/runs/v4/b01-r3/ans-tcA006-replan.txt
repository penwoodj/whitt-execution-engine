# CI Flake Detector End-to-End Report

## 1. Workspace Inventory & Structure

The workspace is located at `/tmp/opencode/flake-run`. It contains three directories: `scripts/`, `outputs/`, and root-level configuration files (`rules.md`, `decisions.md`). All processing is deterministic, using a fixed seed for any randomization (none used here) and standard library Python. No network calls or external installs were made.

**File Layout:**
- `/tmp/opencode/flake-run/rules.md`: Defines thresholds and logic for pass-rate flagging, cluster detection, correlation calculation, and confidence scoring.
- `/tmp/opencode/flake-run/decisions.md`: Documents edge cases encountered (duplicates, missing fields) and how they were resolved per the rules.
- `/tmp/opencode/flake-run/scripts/compute_pass_rates.py`: Stage 1 – Calculates pass rates and flags suspicious tests (5%–95%).
- `/tmp/opencode/flake-run/scripts/find_clusters.py`: Stage 2 – Identifies failure clusters for flagged tests.
- `/tmp/opencode/flake-run/scripts/calculate_correlations.py`: Stage 3 – Computes Pearson correlation between pairs of suspicious tests
