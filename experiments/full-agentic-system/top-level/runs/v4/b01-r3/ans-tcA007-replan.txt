# Alert Storm Dedup Pipeline

## Structure
- `raw/`: Contains synthetic input data (alerts.csv) matching constraints (mixed timestamps, out-of-order).
- `rules/`: Contains logic definitions (`grouping_rule.md`, `severity_norm_rule.md`).
- `scripts/`: Python scripts for each stage using only standard library.
  - `01_group_incidents.py`
  - `02_normalize_severity.py`
  - `03_detect_noise_makers.py`
  - `04_verify_conservation.py` (Independent recomputation)
- `logs/`: Stage execution logs (`stage_01.log`, etc.).
- `outputs/`: Final artifacts.
  - `incidents.json`
  - `storm_report.md`
  - `conservation_check.json`

## Execution Order
Run scripts in order: `01_group_incidents.py` -> `02_normalize_severity.py` -> `03_detect_noise_makers.py`.
Final verification via `04_verify_conservation.py`.
