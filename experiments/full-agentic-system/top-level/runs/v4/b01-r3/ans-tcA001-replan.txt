### Summary of Execution

I have built a complete, dependency-free inventory pipeline under `/tmp/opencode/warehouse-test` as requested. The solution uses only Python 3 standard library (`json`, `os`, `pathlib`, `datetime`, `hashlib`) and Bash for orchestration. No external packages were installed.

The system handles:
1.  **Fixture Generation:** Created 200+ records across 4 subfolders (`inbound`, `outbound`, `quarantined`, `archived`). Included realistic "messiness": malformed JSON (missing commas, trailing braces), duplicate part IDs, and zero quantities.
2.  **Pipeline Stages:**
    *   **Stage 1 (Scan):** Merges valid records into a manifest; quarantines malformed files with reasons to `rejects.json`.
    *   **Stage 2 (Dedupe):** Resolves exact duplicates by file modification time (keeping newest); flags potential logical duplicates (same name/category, different qty) for review. Writes losers to `duplicate_losers.json` and candidates to `review_candidates.json`.
    *   **Stage 3 (Compute):** Calculates distinct parts count, total inventory value
