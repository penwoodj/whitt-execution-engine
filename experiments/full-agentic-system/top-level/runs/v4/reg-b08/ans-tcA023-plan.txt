**rules.md:**

- Version label missing → infer from `X-Request-Version` header; if absent, assign "unknown" and log in `processed/step-1/missing_version.log`
- Error rate threshold = 2.0% (absolute), not relative → defined as error count / total requests
- p95 delta limit = 5% of baseline p95 value → e.g., if baseline is 450ms, max allowed canary p95 = 472.5ms → actual was 472ms → within bound
- Traffic dip at hour 3 (2%) → only include requests where traffic ≥ 2% and version label exists; exclude otherwise
- All percentages must have denominators: e.g., "189/10000 = 1.89%"
- First breach triggers rollback to previous step, not the current one
- Second breach stops climb → status STOPPED
- Rollout_pct = 10 × step number at first breach
- All numbers computed from raw input; no interpolation or smoothing
