- Rule: If a line contains both "error" and "stack", treat as a stack trace; move entire block to ERROR. Triggered by event: Line contains "error" and "stack".
- Rule: On detection of any malformed or corrupted line (e.g., empty, null, or invalid UTF-8), flag it with error code 99 and log location. Triggered by event: Line is empty or invalid.

- Rule: If a line contains "level" followed by a number, extract the number and use it as log level; if not valid, default to INFO. Triggered by event: Line contains "level X".
- Rule: If a line has no clear content or is syntactically invalid (e.g., malformed JSON), classify as UNKNOWN and flag. Triggered by event: Line fails parsing rules.
