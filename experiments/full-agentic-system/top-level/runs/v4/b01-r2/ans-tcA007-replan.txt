# Alert Storm Dedup Pipeline

## Structure
- `rules.md`: Logic definitions (grouping, normalization, noise).
- `scripts/`: Python scripts for processing stages.
  - `01_group.py`: Group alerts into incidents by template/time.
  - `02_normalize.py`: Handle timestamps and severity caps.
  - `03_analyze.py`: Compute metrics and identify edge cases.
- `outputs/`: Generated artifacts.
  - `incidents.json`: List of grouped incidents.
  - `metrics.json`: Aggregated stats (noise makers, span).
  - `disposition.log`: Log for timestamp anomalies.
- `report.md`: Final summary with tables and timings.

## Rules Summary
1. **Grouping**: Alerts with same `template` within 300s window -> Incident.
2. **Timestamp Normalization**: Mixed ISO8601/Unix normalized to ISO8601; out-of-order flagged in log.
3. **Severity Normalization**: All-caps
