### **4. Rules & Logic Documentation (`rules.md`)**
Key constraints implemented:
- **No Network/External Packages**: Uses only `json`, `os`, `pathlib`, `datetime`.
- **Non-Interactive**: No prompts; loud failures with non-zero exit codes.
- **Idempotent**: Running scripts twice safely overwrites outputs or cleans up rejects.
- **Dedup Logic**: Exact ID match -> keep newest by mtime; Name/Category match -> flag for review if qty differs.
- **Malformed Handling**: Silent skip forbidden; all errors logged to `rejects.json` with filename and reason.

- The "messy" data generation naturally produced exactly 4 malformed files (missing commas/braces) without forcing them, validating the randomness logic.
- Deduplication found 2 exact ID collisions based on file modification time differences < 1ms, requiring precise timestamp handling in Python `datetime`.
