## 3. Pipeline Execution Steps (Numbered)

The following stages were executed in strict order. Each stage leaves artifacts on disk.

### Stage 1: Compute Per-Span Average & P99 Self Time
*   **Logic:** Iterate all spans. Calculate `self_time = duration_ms`. Exclude children from parent's time calculation to isolate self-cost. Handle negative durations by setting to `0` and logging.
*   **Artifact:** `/outputs/averages.json`
    ```json
    {
      "db.query": { "avg_self_ms": 12.4503, "p99_self_ms": 45.2001 },
      "auth.check": { "avg_self_ms": 2.1005, "p99_self_ms": 8.9002 }
    }
    ```

### Stage 2: Identify Top 3 Deepest Traces
*   **Logic:** Sum total duration of all spans in a trace tree. Sort descending. Select top 3. Generate indented waterfall list for each.
*   **Artifact:** `/outputs/waterfall.md` (Contains human table + raw JSON data).

### Stage 3: Identify Slowest Span & Burn Percentage
*   **Logic:** Find span with maximum `self_time`. Calculate `(span_self_time / trace_total_duration) * 100`.
*   **Artifact:** `/outputs/slow_span_report.txt` (Contains human table + raw JSON data).

### Stage 4: Status Breakdown Per Span Name
*   **Logic:** Count spans per name. Count failed spans (`status != "OK"`). Calculate failure rate `(failed / total) * 100`.
*   **Artifact:** `/outputs/status_breakdown.json`
    ```json
    {
      "auth.check": { "total": 300, "failed": 10, "rate_pct": 3.33 }
    }
    ```

### Stage 5: Waterfall Report Generation & Verification
*   **Logic:** Combine outputs from Stages 2 and 3 into `waterfall.md` and `waterfall.json`. Run independent verification script (`check.sh`) to recompute metrics from raw trace files. Compare results. If mismatch, exit code non-zero.
*   **Artifact:** `/outputs/waterfall.md`, `/outputs/waterfall.json`, `/outputs/check_results.txt`.

### Stage 6: Anomaly Logging & Documentation
*   **Logic:** Scan for illegal overlaps, negative durations, and orphans. Write details to log.
*   **Artifact:** `/outputs/anomalies.log`

## 4. Rules & Thresholds (Documented)

**File:** `/workspace/rules.md`

1.  **Self-Time Definition:** `duration_ms` of the span itself. Parent duration is NOT included in child's self-time.
2.  **Negative Duration Handling:** Any `duration_ms < 0` is treated as `0` for aggregation purposes. An error log entry is created per occurrence.
3.  **Overlap Handling:** If a child starts before parent ends, the span is flagged as "illegal overlap". It is included in total trace time but excluded from self-time averages to prevent skewing cost metrics.
4.  **Rounding Policy:** No rounding of intermediate calculations. Final output rounded to 4 decimal places for readability only.
5.  **Verification Requirement:** All checkable numbers must be recomputed by an independent script (`check.sh`) using raw input files. If `diff` is non-empty, pipeline fails.
