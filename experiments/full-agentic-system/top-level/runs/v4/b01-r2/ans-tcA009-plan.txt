**Rules Document (`rules.md`):**
```markdown
# Rules & Thresholds for Trace Analysis Pipeline

## Data Handling
- **Negative Durations**: Include in math, flag row with "NEGATIVE" tag.
- **Orphan Spans**: Exclude from parent-child self-time calc; include in global totals if they have a name.
- **Illegal Overlaps**: Flag spans where child start < parent start; do not auto-correct.
- **Rounding**: NEVER round microsecond values. Use full precision (e.g., 1234567.89).

## Output Standards
- **Human Table**: Markdown CSV format, one header row, no merged cells.
- **Machine Copy**: JSON with exact same numeric values as human table (no float conversion loss).
- **Percentages**: Always show denominator (e.g., "12% of 300 traces").
- **Ordering**: Respect dependency chain: Stage 1 -> 2/3 -> 4 -> 5.

## Verification Logic
- Recompute all metrics from raw JSON files independently.
- Exit code 0 only if computed == reported (bitwise equal for integers, epsilon < 1e-9 for floats).
- Hostile reviewer mode: Assume pipeline is wrong until proven otherwise.

## Idempotency
- Scripts must be self-cleaning or overwrite outputs on every run.
- Double-run test required before marking job complete.
```
