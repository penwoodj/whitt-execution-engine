### Stage 1: Workspace Initialization & Data Generation
**Rule:** Create `/tmp/opencode/timeline-run` with `scripts/`, `outputs/`, and root config files (`rules.md`, `decisions.md`). Generate synthetic log data for 6 services (2 UTC, 4 Local) containing specific anomalies (clock skew, gaps) to ensure deterministic chaos.
**Formula:** `mkdir -p /tmp/opencode/timeline-run/{scripts,outputs} && touch /tmp/opencode/timeline-run/rules.md /tmp/opencode/timeline-run/decisions.md`

### Stage 2: Log Parsing & Normalization Script (`normalize.py`)
**Rule:** Read raw logs, parse timestamps (handling UTC vs Local offsets), attach service names, and flag rows with anomalies (skew > 0s or missing lines). Output to `outputs/parsed_logs.csv`.
**Formula:** `python3 /tmp/opencode/timeline-run/scripts/normalize.py`

### Stage 3: Chronological Stream Merge (`merge_stream.sh`)
**Rule:** Sort parsed logs by normalized timestamp, prepend service name and anomaly flags if present. Handle the 2-minute gap in one log explicitly by logging it to `outputs/gap_report.txt`. Output to `outputs/stream.csv`.
**Formula:** `sort -t',' -k3 /tmp/opencode/timeline-run/outputs/parsed_logs.csv > /tmp/opencode/timeline-run/outputs/stream.csv`

### Stage 4: Event Detection Logic (`detect_events.py`)
**Rule:** Scan stream for "Detection" (alert), "Mitigation Attempt 1" (failed patch/restart), and "Resolution" (service healthy). Extract exact log lines as evidence. Output to `outputs/events.json`.
**Formula:** `python3 /tmp/opencode/timeline-run/scripts/detect_events.py`

### Stage 5: Activity Bucketing (`bucket_activity.sh`)
**Rule:** Aggregate events into 5-minute buckets based on normalized time. Count events per bucket. Identify peak activity window. Output to `outputs/activity_chart.csv`.
**Formula:** `awk -F',' '{bin=int($3/300); count[bin]++} END {for(b in count) print b, count[b]}' /tmp/opencode/timeline-run/outputs/stream.csv > /tmp/opencode/timeline-run/outputs/activity_chart.csv`

### Stage 6: Timeline Table Generation (`generate_timeline.py`)
**Rule:** Create a clean Markdown table with columns: Clock Time, Event Type, Evidence Line Reference (Source ID). Ensure no rounding of timestamps. Output to `outputs/timeline.md`.
**Formula:** `python3 /tmp/opencode/timeline-run/scripts/generate_timeline.py`

### Stage 7: JSON Export (`export_json.sh`)
**Rule:** Convert timeline table rows into a structured JSON array where each entry points to the source line number and includes raw anomaly data. Output to `outputs/timeline.json`.
**Formula:** `python3 /tmp/opencode/timeline-run/scripts/export_json.py`

### Stage 8: Verification Script (`verify.sh`)
**Rule:** Recompute key metrics (event counts, bucket totals) from raw inputs using independent logic. Compare against outputs in `timeline.md` and `timeline.json`. Exit non-zero if mismatch. Output verification log to `outputs/verification.log`.
**Formula:** `bash /tmp/opencode/timeline-run/scripts/verify.sh`

### Stage 9: Final Report Generation (`report.py`)
**Rule:** Aggregate all findings (anomalies corrected, events detected, mitigation path) into a single readable report. Include paths to artifacts and timing logs. Output to `outputs/report.md`.
**Formula:** `python3 /tmp/opencode/timeline-run/scripts/report.py`
