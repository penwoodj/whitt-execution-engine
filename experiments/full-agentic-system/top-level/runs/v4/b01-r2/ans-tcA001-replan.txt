# Inventory Pipeline Rules

## Location
All operations occur under: /tmp/opencode/warehouse-test

## Fixture Generation Strategy
- **Total Files:** 200 JSON records generated deterministically (no randomness).
- **Subfolders:** `inbound`, `outbound`, `quarantined`, `archived`.
- **Part ID Format:** `PTM-` followed by 5 digits (e.g., PTM-00142).
- **Categories:** fastener, electrical, housing, consumable, sensor.
- **Statuses:** ok, needs_review, defective.
- **Malformed Data Injection:** ~10% of files intentionally malformed (missing commas, trailing braces) to test robustness.
- **Duplicates:** 
  - Exact Part ID duplicates: 3 instances (newest file wins).
  - Semantic duplicates (Same Name + Category, different Qty): 2 instances flagged for review.
