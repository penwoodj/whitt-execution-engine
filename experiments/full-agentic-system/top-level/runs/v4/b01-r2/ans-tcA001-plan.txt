Here are the steps for building the inventory pipeline, followed by the complete implementation scripts.

### Steps
1.  **Setup Directory Structure**: Create `/tmp/opencode/warehouse-test` with subfolders `inbound`, `outbound`, `quarantined`, `archived`, `scripts`, and output folders for reports/logs.
2.  **Generate Fixture Data**: Write a Python script to generate 200+ JSON files across the four data folders, including realistic noise (malformed JSON, duplicates, zero quantities, specific part ID formats).
3.  **Build Pipeline Stage 1 (Scan & Merge)**: Create `stage_scan.py` to read all valid JSONs into a manifest and move malformed ones to a rejects file with reasons.
4.  **Build Pipeline Stage 2 (Deduplicate)**: Create `stage_dedupe.py` to handle exact part_id duplicates (keep newest) and category/name duplicates (flag for review), logging losers.
5.  **Build Pipeline Stage 3 (Compute Metrics)**: Create `stage_compute.py` to calculate totals, values, rates, top items, and zone breakdowns.
6.  **Build Pipeline Stage 4 (Report Generation)**: Create `stage_report.py` to generate human-readable Markdown and machine-readable JSON reports ensuring data consistency.
7.  **Create Rules Documentation**: Write `rules.md` explaining dedup logic, file handling strategies, and overwrite policies.
8.  **Create Verification Script**: Write `verify.py` to independently recompute metrics from raw fixtures and compare against generated reports, exiting with non-zero codes on mismatch.
9.  **Execute End-to-End Run**: Run the pipeline stages sequentially followed by the verifier.
10. **Capture Outputs & Exit Codes**: Display the final report content and verification status.
