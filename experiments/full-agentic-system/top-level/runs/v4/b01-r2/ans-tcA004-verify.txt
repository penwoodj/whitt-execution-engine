### **Rules & Decisions File (`rules.md`)**

*   **R1:** Timestamps must be ISO-8601; no rounding of milliseconds unless explicitly requested.
*   **R2:** Error rates are percentages `(count_5xx / total_requests) * 100`. Denominator always displayed in table headers.
*   **R3:** Malformed lines (mixed quotes, missing fields) are logged to `outputs/malformed.log` and excluded from rate calculations but included in total event count with a flag.
*   **R4:** Clock-skewed entries (>1 hour deviation from expected sequence) are corrected by aligning to the nearest valid node heartbeat and logged to `outputs/clock_skew_log.txt`.
*   **R5:** Empty rotated files are flagged as "Empty File Detected" in summary; no data is assumed for them.
*   **R6:** Restart events at ~03:00 are identified by a timestamp gap > 1 hour combined with the creation of a new log file (rotation).
*   **R7:** In-flight request death is confirmed only if logs show a request ID appearing in an error log *after* the restart event without completion. If no such orphan exists, count is 0.
*   **R8:** All scripts run twice; second run verifies state consistency (no silent drops).
*   **R9:** Output format: Human table first, then JSON twin with identical numbers. No drift allowed between formats.
