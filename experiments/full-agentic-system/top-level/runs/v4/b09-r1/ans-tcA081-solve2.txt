- Rule: Cumulative size must be computed as sum of prior layer sizes. Triggered by every layer entry after index 0.  
  Reason: Size is cumulative in raw dump; this rule ensures correct aggregation, with threshold at index=0 to avoid double-counting.

- Rule: Flag "install-without-clean" if a layer contains apt-get install and no subsequent layer removes it or cleans up. Triggered when command includes "apt-get install" and no later layer has "rm -rf /var/lib/apt/lists/*" or equivalent cleanup.  
  Threshold: Must have at least one layer with "apt-get install" AND no later layer with cleanup command; if any such layer exists, flag it.

- Rule: Flag "duplicated data adds" when a layer contains identical content (via hash comparison) to a prior layer. Triggered by comparing layer hashes (simulated via size and command similarity); threshold: 90%+ similarity in command and size, with same file paths or known duplicates.  
  Reason: Duplicates indicate redundant storage; this rule is based on observed data patterns from real Docker image dumps.

- Rule: Flag "secrets-in-layer" if a layer contains any string matching 'password', 'secret', 'key', or 'token' in command  
  Threshold: Any occurrence of the keywords in any command line; no threshold needed as it's a presence rule.
