## Rules Invented (`rules.md`)

| Rule | Threshold/Logic | Reason |
|------|-----------------|--------|
| R1: Burst Window | Max lag over any 5-min window > mean + 2σ | Captures "burst" behavior distinct from steady drift |
| R2: Rebalance Correlation | Lag spike must occur within ±30s of rebalance event | Avoids false positives from unrelated traffic |
| R3: Backward Offset Handling | If offset decreases, flag row and compute delta as negative | Data integrity check; prevents silent drops |
| R4: Missing Snapshot Imputation | Linear interpolation between nearest valid snapshots | Prevents gaps in time-series analysis |

---

## Decisions on Mess Types (`decisions.md`)

| Mess Type | Handling Decision |
|-----------|-------------------|
| Missing 20-min snapshot window (rows 14–35) | Imputed via linear interpolation; flagged in `lag-report.md` |
| Offset backward jump at row 78 | Computed delta as negative; logged in `stage1.log`; not dropped |
| Rebalance event without lag spike | Logged but excluded from correlation count (R2) |
