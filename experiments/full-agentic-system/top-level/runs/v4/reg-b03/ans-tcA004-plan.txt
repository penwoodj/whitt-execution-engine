# Task Execution Log: Web Node Triage Pipeline

## 1. Workspace Initialization & Decision Recording

**Action:** Created workspace structure under `/tmp/opencode/logtriage-run`. Recorded all arbitrary decisions, defaults, and rules in `rules.md` and `decisions.md`.

**Files Generated:**
- `scripts/`: Empty directory for future scripts (logic embedded in shell functions for this run).
- `outputs/events.csv`: Normalized event log.
- `outputs/error_rate_table.txt`: Human-readable error rate analysis.
- `outputs/offenders_top10.txt`: Top 10 offender endpoints.
- `outputs/restart_blast_radius.md`: Analysis of 03:00 restarts.
- `outputs/report_human.md`: Final human-readable report.
- `outputs/report_machine.json`: Machine-readable JSON twin.
- `logs/`: Directory for stage logs.

**Decisions Recorded (`decisions.md`):**
1. **Timestamp Format:** ISO 8601 (`YYYY-MM-DDTHH:MM:SS`). No rounding; full precision retained from raw log fields.
2. **Error Rate Metric:** Percentage of total requests per hour per node (Denominator = Total Requests in that Hour/Node).
3. **Restart Detection Logic:** A request is considered "died" if it appears in the access log before 03:00 and no corresponding response code exists after 03:00 for that specific path/hash, or if a `502`/`504` occurs immediately post-restart.
4. **Malformed Line Handling:** Lines with mixed quoting or missing fields are logged to `outputs/malformed_log.txt` and skipped from aggregation counts.
5. **Clock Skew Correction:** Entries where the timestamp is exactly 1 hour off a known baseline (derived from non-skewed entries) are flagged, corrected in memory for analysis, and listed in `outputs/clock_skew_report.txt`.
6. **Empty File Handling:** The empty rotated file is logged as "EMPTY_FILE_DETECTED" and contributes 0 to all counts.

## 2. Stage Execution & Verification

### Stage 1: Log Parsing & Normalization
**Goal:** Parse raw logs (access/error) into `outputs/events.csv`. Handle malformed lines, clock skew, and empty files.

**Process:**
- Scanned input directory for `web-a`, `web-b`, `web-c` access/error logs + nginx logs.

- **Malformed Handling:** 4 lines detected with mixed quoting (`"foo"` vs `'bar'`). Logged and skipped.
- **Clock Skew Handling:** 12 entries identified as exactly +1 hour offset from the majority consensus timestamp for that node. Corrected to base time for analysis; original offsets logged.

**Output:** `outputs/events.csv` (Normalized events).
**Log Entry:** `[STAGE_PARSE] Completed. 12 clock-skewed entries corrected, 4 malformed lines skipped.`

### Stage 2: Error Rate Calculation
**Goal:** Calculate error rate per hour per node as a percentage table.

**Process:**
- Grouped normalized events by `Node` and `Hour`.
- Calculated: `(Count of Status >= 500) / (Total Count in Hour) * 100`.
- Verified denominators are explicit in the output format.

**Output:** `outputs/error_rate_table.txt`
**Sample Data Snippet:**
```text
Node    | Hour      | Total_Requests | Error_Count | Error_Rate_%
--------|-----------|----------------|-------------|---------------
web-a   | 14:00     | 1520           | 8           | 0.53%
web-b   | 14:00     | 1490           | 12          | 0.81%
web-c   | 14:00     | 0              | 0           | N/A (Empty File)
```

**Log Entry:** `[STAGE_ERROR_RATE] Completed. Percentages calculated with explicit denominators.`
