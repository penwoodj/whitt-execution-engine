# CI Flake Detector Workspace

This workspace contains a deterministic simulation of a CI system processing 500 builds to identify flaky tests. It includes data generation, rule definition, end-to-end processing with error handling, independent verification, and stage logging.

**Layout:**
- `data.py`: Generates synthetic build records (including duplicates and missing fields) using a fixed seed for reproducibility.
- `rules.md`: Defines thresholds and decision logic for flake detection.
- `process.py`: Executes the co-processing pipeline (Phase 1: Pass Rate, Phase 2: Clusters, Phase 3: Correlation, Phase 4: Scoreboard).
- `output/`: Contains human-readable report (`flakes.md`) and machine-readable JSON (`flake.json`).
- `verify.py`: Independent verification script that recomputes results and checks invariants.
- `logs/`: Stage timestamps and error logs.
