# Phase 1: Rule Scan & Disposition Log

**Decisions File Content (Simulated `/tmp/opencode/decisions.md`)**

```markdown
# Decisions Log: Perf Regression Tracker Run

## 1. Data Normalization Strategy
- **Issue:** One scenario has only one repeat instead of three.
- **Decision:** Per Rule A, use the single value for both Best and Median. Set `single_repeat: true`. Do not discard data.
- **Rationale:** "Data wins." Discarding violates the requirement to surface mess instances.

## 2. Delta Calculation Precision
- **Issue:** Requirement states "don't round anything".
- **Decision:** Calculate percent change as $((New - Old) / |Old|) \times 100$. Keep full floating-point precision (e.g., `10.3456789`). No rounding to 2 decimals unless explicitly requested for display, but internal state remains precise.
- **Rationale:** "Ugly precise number is better than tidy lie."

## 3. Timestamp Ambiguity Resolution
- **Issue:** Two commits share an identical timestamp.
- **Decision:** Per Rule E, treat the commit appearing later in the input file order as the "New" commit for delta calculation.
- **Rationale:** Ensures deterministic ordering without external clock dependency.

## 4. Outlier Handling
- **Issue:** Timings have outlier spikes from machine noise.
- **Decision:** Per Rule F, do NOT filter outliers. Include them in raw data but flag with `noise_suspect` if variance is high within a scenario's repeats (or simply flag the specific row if it deviates significantly).
- **Rationale:** "Machine noise spikes are not filtered out."

## 5. Refactor Audit Threshold
- **Issue:** One commit claims to be pure refactor but shows slowdown.
- **Decision:** Per Rule D, audit this specific commit. If ANY scenario shows >10% slowdown (regardless of general regression thresholds), mark `refactor_audit_fail`.
- **Rationale:** "Regardless of general regression thresholds."

## 6. Output Format Consistency
- **Issue:** Deliverables must agree between human (Markdown) and machine (JSON).
- **Decision:** Use identical numeric values in both outputs. JSON will contain the raw computed floats; Markdown tables will display them identically. No drift allowed.
```
