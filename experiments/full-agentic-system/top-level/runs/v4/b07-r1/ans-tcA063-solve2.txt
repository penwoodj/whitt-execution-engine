Phase 1 RULE SCAN:

- Daily backup rule: A new daily backup is created every day at midnight, with a size drawn from [100MB, 250MB] uniformly, corruption chance set to 1% per snapshot. Triggered by: daily event (every day).
- Weekly promotion rule: On the first day of each week, all daily backups from the prior week are promoted to weekly tier if they are at least 7 days old and have not been corrupted. Triggered by: weekly day (day 0 of week).
- Monthly promotion rule: On the first day of each month, all weekly backups from the prior month are promoted to monthly tier if they are at least 4 weeks old and have not been corrupted. Triggered by: monthly day (day -1 of month).
- Grandfather-father-son rotation rule: A snapshot is retained only if it satisfies the grandfather-father-son hierarchy: daily backups are kept for 7 days, weekly backups for 4 weeks, monthly backups for 12 months. If a backup fails to meet tier retention, it is removed from that tier and falls back to the previous tier (e.g., a corrupted daily backup is dropped; if no prior tier exists, it is discarded). Triggered by: every day during rotation check.
- Corrupted snapshot fallback rule: When a retained snapshot corrupts, it is immediately removed from its current tier and falls back to the previous tier. If no prior tier exists, the snapshot is discarded. Triggered by: corruption event (on any backup that fails integrity check).
- Restore-drill eligibility rule: A restore drill request is valid only if the requested snapshot exists in a tier and has not been corrupted. If the snapshot does not exist or is corrupted, the drill fails. Triggered by: random restore drill on any day.
- Promotion ambiguity resolution rule: On days when both weekly and monthly promotion occur (e.g., first day of month), weekly promotions are processed first, then monthly promotions. Triggered by: overlapping weekly/monthly event (first day of month).
- Tier retention violation rule: Any backup that exceeds its tier retention period is removed from the current tier and falls back to the previous tier; if no prior tier exists, it is discarded. Triggered by: daily rotation check.
- Seed corruption rule: Each snapshot has a 1% chance of corruption independently at creation time. Triggered by: daily backup creation.
