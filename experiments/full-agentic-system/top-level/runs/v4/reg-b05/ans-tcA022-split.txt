(1) FIRST HALF SCOPE — rules and event lines belonging to the first half of the task (aggregation, raw-counts, sanity checks, compression report, stage logging):

- Aggregate per-service, per-five-minute window using mean, max, sum, error rate, saturation peak from raw minute-level data.  
  Formula: For each service and each five-minute interval (e.g., 00:00–00:05), compute:  
    latency_mean = mean(latency) over minutes in the window  
    latency_max = max(latency) over minutes in the window  
    traffic_sum = sum(traffic) over minutes in the window  
    error_rate = (sum(errors)) / (traffic_sum + 1) if traffic_sum > 0 else 0  
    saturation_peak = max(saturation) over minutes in the window  

- Preserve raw-count column: for each five-minute window, record how many original minute rows contributed to it.  
  Rule: raw_count = number of minute records (rows) that fall within the five-minute interval and service group.
