Phase 1 RULE SCAN:

- Failed-login frequency by IP: triggers when a log entry contains "failed login" and has an IP address; counts per IP, top twenty with counts.  
- Path scanning detection: triggers when a log entry has HTTP status 404 and the path is not in a known legitimate directory (e.g., /static/, /api/); records distinct paths from one source IP.  
- /admin hammer detection: triggers when an IP makes more than 5 requests to "/admin" within a 1-minute window; tracks start time, stop time, and request rate per IP.  
- Whitelist pass rule: triggers when a log entry matches a known legitimate crawler pattern (e.g., User-Agent: "Googlebot", "Bingbot") or comes from an IP in a predefined whitelist; excludes such entries from failed-login, path scanning, and /admin hammer counts.  
- Expiry rule for failed-login frequency: after 24 hours of no new failed logins from an IP, the entry is removed from the top twenty list.  
- Return rule for path scanning: if a 404 path appears in less than 3 distinct logs from one source, it is marked as noise and not counted.  
- Revocation rule for /admin hammer: if an IP stops making requests to "/admin" after a peak rate of over 10 per minute, the hammer event is revoked and no longer tracked.
