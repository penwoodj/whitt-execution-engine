# Rules Document: Access Log Security Sweep

## 1. Failed-Login Frequency by IP (Top Twenty)
- **Formula**: Count log entries containing "failed login" and an IP address.
- **Filter**: Exclude entries from whitelisted IPs or with User-Agent matching known crawler patterns.
- **Aggregation**: Group by IP, count per IP, sort descending by count.
- **Threshold**: Top 20 IPs retained; all others discarded.
- **Expiry Rule**: After 24 hours of no new failed login events from an IP, remove
