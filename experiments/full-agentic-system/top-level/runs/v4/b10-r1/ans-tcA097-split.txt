(1) FIRST HALF SCOPE — rules and event lines belonging to steps 1 through 2 (per-machine-class mtbf, std, interval comparison; just-missed pattern statistical test with edge cases surfaced)

Rules:

- For each machine class, compute the time between failures (TBF) from failure timestamps in logs, using only entries where failure code is non-zero and marked as "failure" (code ≠ 0), excluding corrective maintenance entries (code = 0).  
- TBF values are calculated as difference between consecutive failure events for each machine, with the first failure assumed to be at time zero if no prior event exists.  
- For each class, compute mean time between failures (MTBF) and standard deviation (std) of TBFs using raw timestamps, preserving full precision.  
- The service interval length per machine class is taken from the maintenance log entry for that class, stored in a column named "interval_days".  
- Side-by-side output must include: MTBF, std, interval_days, and the number of failures used to compute each statistic.  
- All values are reported with full precision (no rounding), including decimals.
