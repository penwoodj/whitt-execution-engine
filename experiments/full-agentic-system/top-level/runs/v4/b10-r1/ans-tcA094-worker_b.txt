Phase 1 RULE SCAN:

- Elevator window expiry rule: triggers when an elevator slot ends (e.g., at 14:00), revokes all pending carries and shuttles scheduled after that time.  
- Desk must go during elevator window rule: triggers when the desk item is identified; it cannot be carried via stairs, so any carry attempt outside elevator window fails and is marked as invalid.  
- Fragile box stacking restriction rule: triggers when a fragile box is encountered in a shuttle sequence; if stacked with another box, the entire shuttle is invalidated and must be re-planned.  
- Item duplication detection rule: triggers when two entries for the same item (e.g., "desk" vs. "office desk") are found; flags both rows and applies a merge rule to resolve conflict by keeping the first entry and logging the duplicate.  
- Mover pairing requirement rule: triggers when a heavy item is scheduled; requires both movers to be assigned, and if only one is available at time of carry, the event fails with error.  
- Stairwell fit rule: triggers when an item (the desk) is assessed for stairwell passage; if it does not fit, the carry must occur during elevator window only.  
- Refill rule: triggers after a shuttle completes and no items remain in a floor; allows reassignment of unassigned boxes to next available slot with 10% probability (threshold: 50% of total box count), but only if no prior failure occurred.  
- Fallback rule: triggers when a carry or shuttle fails due to timing, mover availability, or space constraints; reroutes the item to the next available elevator window and logs the delay as +30 minutes.  
- Source-ranking rule: triggers during schedule generation; ranks items by size (small → large), then by fragility, then by floor origin; determines carry order for non-elevator moves.
