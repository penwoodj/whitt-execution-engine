### 1. Workspace Layout & Rules Definition

**Directory Structure:**
```text
/tmp/opencode/csvmerge-run/
├── rules.md          # Logic definitions (headers mapping, trust order)
├── scripts/
│   ├── setup.sh      # Creates fake data with specific "messiness"
│   ├── merge.sh      # Normalizes headers and applies trust logic
│   └── verify.sh     # Independent check script (recomputes from raw)
├── outputs/
│   ├── merged.csv    # Final unified customer table
│   ├── conflicts.csv # Ledger of cell-level disagreements
│   └── ledger-summary.json # Machine-readable stats
└── README.md         # Entry point, instructions, and file map
```

**Rules (`rules.md`):**
1.  **Header Canonicalization:** `email_address`, `billing_email`, `crm_email` $\to$ `email`. All other casing variations ignored; tab-separated files treated as CSV (comma delimiter).
2.  **Trust Order (Conflict Resolution):** If a customer ID exists in multiple sources, values are prioritized: `Billing System` > `CRM System` > `Spreadsheet
