Here is the complete end-to-end processing exercise for capacity forecasting, self-contained in `/tmp/opencode/forecast-run`, using only standard library Python and Bash. It handles missing data, outliers, linear trends, seasonality, projections with error bars, hardware purchase decisions, verification, and deterministic reproducibility.

---

## 📁 Workspace Layout

```
/tmp/opencode/forecast-run/
├── README.md          # Entry point, structure explanation
├── rules.md           # All thresholds, logic, and reasons
├── data_raw.csv       # Input: 12 months × 6 services (with issues)
├── scripts/
│   ├── clean.py       # Handle missing/outliers
│   ├── fit.py         # Linear + seasonal fits
│   ├── project.py     # 6-month projections with error bars
│   └── decide.py      # Hardware purchase decision logic
├── outputs/
│   ├── forecast.md    # Human-readable report
│   ├── forecast.json  # Machine-parseable numbers
│   └── decisions.md   # Work on hardware decisions
├── verifier.py        # Recomputes key numbers from raw inputs
