**Step 2: Data Cleaning Script (`scripts/clean.py`)**
- Load raw CSV.
- Detect and log missing rows per service (Jan).
- Detect and log outliers per service (Dec) using IQR method or Z-score > 3.
- Correct timestamp skew (assume +1 hour offset if detected via string pattern mismatch).
- Output cleaned data to `data/cleaned.csv` with a header row indicating corrections applied.

**Step 3: Trend Fitting Script (`scripts/trend.py`)**
- Load cleaned data.
- For each service, fit Linear Regression ($y = mx + b$) using Ordinary Least Squares (OLS).
- Calculate $R^2$, slope ($m$), intercept ($b$), and standard error of estimate.
- Log edge cases: services with low variance, high residuals, or near-zero slopes.
- Output summary table to `logs/trend_summary.txt`.

**Step 4: Seasonal Detection Script (`scripts/season.py`)**
- Identify seasonal services (E, F) from data patterns or metadata.
- Detect season period ($P$) by finding autocorrelation peaks or visual inspection of residuals after detrending.
- Calculate amplitude ($A$) as half the difference between peak and trough values in the residual series.
- Log method used (e.g., "Autocorrelation lag 12 identified").
- Output summary to `logs/season_summary.txt`.

**Step 5: Projection Script (`scripts/project.py`)**
- Combine linear trends for A-D and seasonal models for E-F.
- Generate forecasts for next 6 months (Months 13-18).
- Calculate prediction intervals ($\pm 2 \times SE$) based on residual variance.
- Do not round intermediate calculations; preserve full precision until final output formatting.
- Output raw JSON to `outputs/forecast_raw.json` and formatted Markdown table to `outputs/forecast.md`.

**Step 6: Capacity Crossing Analysis (`scripts/capacity.py`)**
- Define current capacity ceiling for each service (assume arbitrary but logged value, e.g., $C_{max}$).
- Solve inequality $Forecast(t) \ge C_{max}$ for $t$.
- Identify Q3 crossing points (Months 13-15).
- Log services that do not cross in Q3.
- Output to `logs/capacity_crossing.txt`.

**Step 7: Verification Script (`scripts/verify.py`)**
- Read raw inputs and cleaned data independently.
- Re-implement OLS, seasonal amplitude detection, and projection logic without importing pipeline modules.
- Compare computed values against `outputs/forecast_raw.json`.
- Exit with code 0 if match within floating-point tolerance; exit non-zero otherwise with specific mismatch report.

**Step 8: Final Report Generation (`scripts/report.py`)**
- Aggregate all logs, timings, and verification results.
- Generate `report.md` with human-readable tables at top and machine-readable JSON block below.
- Include timing table showing duration of each stage.
- Ensure deterministic output by seeding random number generators (if any) or using fixed logic paths.

**Step 9: Reproducibility Test**
- Run full pipeline twice in sequence.
- Compare checksums (`sha256sum`) of all output files between runs.
- Log "PASS" if identical, "FAIL" otherwise with diff details.
