### Phase 1: Rule List (Strict Constraints)

1.  **Workspace:** All artifacts must reside in `/tmp/opencode/subs-run`.
2.  **Format:** Human reports use Markdown tables; Machine data uses JSON with identical numeric precision to human text.
3.  **Integrity:** No silent absorption of errors; every malformed cue, overlap, gap, or speed violation is logged and surfaced.
4.  **Precision:** Timestamps must not be rounded into meaninglessness (e.g., `00:00:10.5` vs `00:00:10`).
5.  **Verification:** Every stage runs twice; a separate independent verifier script recomputes and checks invariants before finalization.
6.  **Documentation:** All rules, thresholds, and decisions are written to disk (e.g., `rules.md`, `decisions.md`) next to scripts.
7.  **Tone:** Plain sentences, no buzzwords; percentages always include denominators (e.g., "12% of 800").
