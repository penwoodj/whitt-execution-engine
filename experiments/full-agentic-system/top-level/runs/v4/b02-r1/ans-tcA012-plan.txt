### Step 3: Availability Calculation Pipeline
**Rule:** Compute daily and monthly-to-date availability per service using the formula: `Availability = (Total Minutes - Down Minutes) / (Total Minutes + Missing Minutes * 0)` where Missing Minutes are excluded from the denominator.
**Action:** Run script to parse raw data, flag missing checks explicitly in output rows, calculate precise unrounded percentages with denominators displayed, and generate `availability.csv` and `availability_summary.json`.

### Step 4: Error Budget Sizing & Burn Rate Analysis

**Action:** Generate `budget_sizing.csv` showing remaining budget timeline, calculate daily burn rates with precise numbers, and flag any day where `Burn_Rate > 3x Sustainable_Burn_Rate`.
