# CI Flake Detector Workspace Report

## 1. Workspace Inventory & Structure

The workspace is located at `/tmp/opencode/flake-run`. It contains a deterministic Python script that processes simulated CI data to detect flaky tests, compute pass rates, identify failure clusters, and calculate correlations. The structure follows the requirements: scripts in `scripts/`, outputs in `outputs/`, rules in `rules.md`, and decisions in `decisions.md`.
