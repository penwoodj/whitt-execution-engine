```markdown
# rules.md — Subtitle Repair Pipeline Rules

## 1. Parsing Stage (`parse.py`)
- **Rule P1**: Every cue must have exactly one speaker label line before the text. If two lines exist, split into two cues with empty second label.
- **Rule P2**: Timestamps must be in `HH:MM:SS,mmm --> HH:MM:SS,mmm` format. Comma or period used inconsistently triggers a flag but does not halt parsing.
- **Rule P3**: Cues with no text are flagged as empty and preserved (not dropped).

## 2. Timing Fix Stage (`fix_timing.py`)
- **Rule T1**: Overlapping cues: trim the start of the later cue to match the end of the earlier one.
- **Rule T2**: Gaps >5 seconds: report only, do not auto-fill unless explicitly requested (not in scope).
- **Rule T3**: Durations <0.5s: extend duration by adding 0.1s to start time, preserving end time relative to original flow.
- **Rule T4**: Renumbering: sequential integers starting at 1 after all fixes.

## 3. Reading-Speed Stage (`speed_check.py`)
- **Rule S1**: Max reading speed = 21 characters per second (including spaces). If exceeded, split cue into two parts with midpoint insertion of pause.
- **Rule S2**: Split point chosen to minimize word fragmentation; if impossible, extend duration instead.

## 4. Output Consistency
- All timestamps retain millisecond precision without rounding.
- Percentages always include denominator (e.g., "12% of 800 cues").
- Every defect instance is surfaced in both `repair-report.md` and `defects.json`.

## 5. Verification (`verify.py`)
- Recomputes all stages independently from raw input.
- Checks:
  - Cue count matches before/after.
  - No overlaps remain.
  - All gaps ≤5s (reported if >0).
  - All durations ≥0.5s.
  - Max reading speed ≤21 cps.
  - Sequential numbering from 1 to N.
- Exits nonzero on any mismatch.
```

```markdown
# decisions.md — Assumptions for Unspecified Fields

## Default Behavior
- **Gap Handling**: Gaps >5s are reported but not filled unless explicitly requested. This avoids silent data fabrication.
- **Speaker Label Splitting**: When a cue has two speaker lines, the second is treated as continuation text with empty label prefix.
- **Timestamp Normalization**: Mixed separators (comma/period) are normalized to comma internally; original format preserved in output if consistent within cue.

## Thresholds
- **Reading Speed**: 21 characters per second (including spaces). Chosen based on average adult reading rate for subtitles.
- **Minimum Duration**: 0.5 seconds. Below this, user experience suffers due to flicker or unreadability.
- **Overlap Resolution**: Trim later cue start time to match earlier cue end. No content loss; only timing adjustment.

## Output Format
- **Human Report**: Markdown with tables for skimming on phone.
- **Machine Log**: JSON with same numbers as human report, no drift allowed.
- **Timestamps**: Recorded at start/end of each stage in `timings.txt`.

## Error Handling
- Malformed cues are flagged but not dropped unless explicitly instructed (not in scope).
- Contradictions between data and rules are reported side-by-side with both rule and row visible.
```

### 🛠️ scripts/parse.py (Stage 1: Parse & Flag Malformed Cues)
```python
#!/usr/bin/env python3
import re, json, sys, os
from datetime import datetime

def parse_timestamp(ts):
    # Normalize timestamp to HH:MM:SS,mmm --> HH:MM:SS,mmm
    ts = ts.replace('.', ',')  # Handle mixed separators
    parts = ts.split(' --> ')
    if len(parts) != 2:
        return None, "Invalid timestamp format"
    start_str, end_str = parts
    try:
        start_ms = int(start_str.split(',')[-1])
        end_ms = int(end_str.split(',')[-1])
        return (start_ms, end_ms), None
    except Exception as e:
        return None, f"Parsing error: {e}"

def parse_srt(filepath):
    with open(filepath) as f:
        content = f.read()
    
    cues = []
    current_cue = {"index": 0, "timestamp": "", "speaker_label": "", "text": ""}
    
    for line in content.splitlines():
        if not line.strip():
            if current_cue["index"] > 0:
                cues.append(current_cue)
                current_cue = {"index": 0, "timestamp": "", "speaker_label": "", "text": ""}
            continue
        
        if re.match(r'^\d+$', line):
            if current_cue["index"] > 0:
                cues.append(current_cue)
            current_cue["index"] = int(line)
            current_cue["timestamp"] = ""
            current_cue["speaker_label"] = ""
            current_cue["text"] = ""
        elif not line.strip().startswith('-->'):
            if current_cue["timestamp"]:
                current_cue["speaker_label"] += " " + line.strip()
            else:
                current_cue["speaker_label"] = line.strip()
        else:
            current_cue["text"] += " " + line.strip()
    
    if current_cue["index"] > 0:
        cues.append(current_cue)
    
    return cues

def flag_malformed(cues):
    flagged = []
    for cue in cues:
        ts, err = parse_timestamp(cue["timestamp"])
        if err:
            flagged.append({
                "rule": "P2",
                "row": cue["index"],
                "error": err,
                "original": cue["timestamp"]
            })
        
        lines = cue["speaker_label"].split('\n')
        if len(lines) > 1:
            flagged.append({
                "rule": "P1",
                "row": cue["index"],
                "error": f"Multiple speaker labels detected in cue {cue['index']}",
                "original": cue["speaker_label"][:50] + "..."
            })
        
        if not cue["text"].strip():
            flagged.append({
                "rule": "P3",
                "row": cue["index"],
                "error": "Empty text in cue",
                "original": cue["text"]
            })
    
    return flagged

if __name__ == "__main__":
    input_file = "/tmp/opencode/subs-run/data/input.srt"
    cues = parse_srt(input_file)
    flagged = flag_malformed(cues)
    
    # Write logs per line, one entry each
    with open("/tmp/opencode/subs-run/logs/stage1.log", "w") as f:
        for cue in cues:
            ts, err = parse_timestamp(cue["timestamp"])
            status = "OK" if not err else f"ERROR: {err}"
            f.write(f"CUE {cue['index']}: {status}\n")
    
    # Write defects.json
    with open("/tmp/opencode/subs-run/outputs/defects_stage1.json", "w") as f:
        json.dump(flagged, f, indent=2)

    print("Stage 1 complete. Flagged malformed cues.")
```
