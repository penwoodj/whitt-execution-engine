# Normalized Schema Rationale

## Tables

### products (Main Catalog)
- **id**: INTEGER PRIMARY KEY AUTOINCREMENT
- **name**: TEXT NOT NULL (Cleaned, trimmed)
- **description**: TEXT (Nullable)
- **price_numeric**: REAL NOT NULL (Currency stripped, converted to float)
- **currency_code**: TEXT CHECK(currency_code IN ('USD', 'EUR')) (Explicit type)
- **tags**: TEXT (Comma-separated string for quick filtering, normalized)
- **created_at**: DATETIME DEFAULT CURRENT_TIMESTAMP

### suppliers
- **id**: INTEGER PRIMARY KEY AUTOINCREMENT
- **name**: TEXT NOT NULL UNIQUE
- **region**: TEXT (Nullable)

### product_suppliers (Junction Table)
- **product_id**: INTEGER REFERENCES products(id)
- **supplier_id**: INTEGER REFERENCES suppliers(id)
- **PRIMARY KEY (product_id, supplier_id)**

## Rules for Normalization
1.  **Atomicity**: Nested JSON arrays (suppliers) are flattened into a junction table to prevent duplication and allow many-to-many relationships.
2.  **Type Safety**: Prices stored as strings in input are coerced to REAL in DB. Currency symbols ($) removed before conversion.
3.  **Tag Normalization**: Comma-separated strings split, trimmed, lowercased, and rejoined for consistent indexing.
