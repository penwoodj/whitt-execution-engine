    *   Create `tasks.md` with exactly 12 analytical questions (including 2 unanswerable ones based on missing timestamps).

3.  **Build Grading Harness**
    *   Create `scripts/grade.py`.
    *   Logic: Read `tasks.md` (or hardcoded list), read candidate solution file, compare against `answers.txt`.

    *   Output format: Score/12, Pass/Fail (threshold 10), and detailed per-question miss report.

4.  **Generate Candidate Solutions**
    *   Create `scripts/gen_candidates.py`.
    *   Generate `solution-perfect`: Correctly answers all 12 questions based on data analysis.

    *   Generate `solution-hallucinate`: Answers the 2 unanswerable questions with fabricated numbers instead of "NOT_ANSWERABLE".
    *   Generate `solution-empty`: Leaves >50% of lines blank.

5.  **Execute Meta-Test (Original Dataset)**
    *   Run grader on all four candidates against original data.

6.  **Implement Mutation & Regression Test**
    *   Create `scripts/mutate.py`.
    *   Logic: Perturb dataset (swap severities, reassign issues, change dates), recompute ground truth answers (`answers_new.txt`), regenerate `solution-perfect` for new data.
    *   Run grader on stale candidates vs. new answers and new perfect solution.
    *   Output comparison table showing score shifts before/after mutation.
