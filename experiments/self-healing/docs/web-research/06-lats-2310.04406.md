# Source: LATS — Language Agent Tree Search

- **URL:** https://arxiv.org/abs/2310.04406
- **Retrieved:** 2026-08-24 (abstract + websearch)

## Method Mechanics

MCTS over agent trajectories:

```
for episode in 1..k:            # k = 10-25 episodes budget
    select node via UCT
    expand: candidate actions via LLM
    evaluate: self-consistency score + environment feedback
    simulate rollout
    backpropagate value
    reflect: add insight to node memory
```

- **Budget:** k=10–25 MCTS episodes
- Combines Reflexion memory + tree search + self-consistency evaluation

## Healing Trigger

Not failure-triggered — continuously searches for better trajectory. Healing = choosing alternative branch.

## Metrics

92.7% HumanEval (GPT-4), 75.9 WebShop. Highest perf among 2023 methods, highest cost too.

## What We Borrow

1. **Branch diversity concept** — after heal, next attempt is a DIFFERENT strategy branch, not re-run of same prompt. Our heal chain: F1→corrective prompt ≠ F3→replan ≠ F2→tool swap. Strategy-per-class routing = coarse 3-branch tree.
2. **Self-consistency as node evaluator** — see 08 doc; spoofed as consistency component C in R score
3. **Explicit budget accounting** — episodes counted; our attempt counter + report.py token/hook budget = same discipline at deterministic scale

## Divergence (explicit)

Full MCTS = multiple parallel inference calls per node. FORBIDDEN in this experiment's zero-LLM phase and too expensive for 4B–9B local hardware (RX 580). LATS noted as future upper-bound comparator only. Our v1 = greedy single-path with class-routed heal (linear chain, deterministic).
