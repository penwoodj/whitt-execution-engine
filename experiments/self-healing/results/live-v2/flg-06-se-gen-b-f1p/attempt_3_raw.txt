# Architecture Overview

## Core Design Principles
The `iridium-recon` crate is designed as an **async-first**, **streaming** reconciliation engine built on Tokio to handle high-volume shipment event pairs between a primary (Rust ingest tier) and secondary (carrier integration) stream. The architecture prioritizes:
- **Deterministic output**: Hash-based iteration order stability via deterministic hashing of event fingerprints.
- **Streaming efficiency**: Memory-efficient processing with configurable watermark windows to handle lag up to 90 seconds.
- **Fault tolerance**: Clear error boundaries for orphaned/ghosted events and retry-safe secondary stream handling.

## Crate Layout
The library is structured as a **single public crate** (`iridium-recon`) with:
1. A **core pairing engine** (`PairingEngine`) implementing the reconciliation algorithm.
2. An **async facade** (`ReconciliationService`) for integration with Prometheus metrics and storage facades.
3. **Private utilities** (`utils::event_utils`, `utils::metrics`) handling validation, fingerprinting, and logging.

## Key Tradeoffs
- **Watermark vs. Lag**: Configurable window size balances false positives (orphaned events) against missed ghosted events.
- **Duplicate Handling**: Retry indicators in secondary events enforce at-least-once semantics without requiring deduplication logic.
- **Determinism**: SHA-256 fingerprinting + event kind ensures consistent iteration order despite timestamp skew.

## Algorithm Walkthrough
### Pseudocode with Complexity Bounds
```rust
async fn pairing_engine(
    config: &ReconciliationConfig,
    primary_stream: AsyncStream<PrimaryEvent>,
    secondary_stream: AsyncStream<SecondaryEvent>
) -> CarrierReport {
    let mut primary_buffer = Vec::with_capacity(config.watermark_seconds * 10); // ~90s buffer
    let mut ghosted_events = HashMap::new();
    let mut orphaned_events = Vec::new();

    for event in primary_stream {
        let PrimaryEvent { ulid, kind, sequence, fingerprint, timestamp } = event;
        primary_buffer.push((ulid, sequence, timestamp));

        // Watermark check: drop events older than watermark.
        if timestamp < Utc::now() - chrono::Duration::from_secs(config.watermark_seconds) {
            continue;
        }

        // Check for duplicates in secondary stream (via fingerprint).
        let is_duplicate = ghosted_events.contains_key(&fingerprint);
        if is_duplicate {
            orphaned_events.push(Orphaned { ulid });
        } else {
            ghosted_events.insert(fingerprint, Orphaned { ulid });
        }
    }

    // Process secondary stream with retry handling.
    for event in secondary_stream {
        let SecondaryEvent { ulid, kind, sequence, fingerprint, timestamp, carrier_code, is_retry } = event;

        if is_retry && ghosted_events.contains_key(&fingerprint) {
            continue; // Skip retries (handled by at-least-once semantics).
        }

        // Check for orphaned primary events.
        let orphaned = match ghosted_events.remove(&fingerprint) {
            Some(Orphaned { ulid: expected_ulid }) => {
                if ulid != expected_ulid {
                    continue; // Ignore mismatched retries (assumed carrier error).
                }
                None
            },
            None => Some(Ghosted { ulid, carrier: carrier_code }),
        };

        if let Some(orphaned) = orphaned {
            orphaned_events.push(orphaned);
        } else {
            // Matched event.
            primary_buffer.retain(|&(ulid, seq, _)| seq >= sequence); // Prune stale entries.
        }
    }

    // Generate deterministic report.
    let mut report = CarrierReport::new();
    for (carrier, events) in orphaned_events.group_by(|e| e.carrier_code) {
        report.add_carrier(carrier, events);
    }

    return report;
}
```

### Complexity Analysis
- **Time**: O(N log N) for watermark pruning + O(M) for ghosted event lookup (HashMap).
- **Space**: O(W * K) where W = watermark window, K = avg. sequence range per event.
- **Determinism**: Fingerprint + kind hash ensures stable iteration order via `std::collections::hash_map::DefaultHasher` with fixed seed.
