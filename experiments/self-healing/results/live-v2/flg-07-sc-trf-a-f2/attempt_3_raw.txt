# **Coastal Erosion Data Pipeline Specification**
*Raw Daily JSON → Monthly Analysis-Ready Parquet*

---

## **1. Schema Mapping**

### **Target Columns & Source Variants**
| Target Column          | Unit       | Firmware v1 (Int)               | Firmware v2 (Str)               | Firmware v3 (Offshore)         |
|------------------------|------------|----------------------------------|---------------------------------|-------------------------------|
| `station_id`           | string     | `station_id` → lowercase ASCII   | `station_id` → lowercase ASCII  | `station_id` → lowercase ASCII |
| `window_start_utc`     | seconds    | `timestamp` (local time) + offset | `timestamp` (UTC)              | `timestamp` (UTC)             |
| `wave_height_mean`     | meters     | `hs_mean`                         | `wave_height_mean`              | `wave_height_mean`            |
| `wave_height_max`      | meters     | `hs_max`                          | `wave_height_max`               | `wave_height_max`             |
| `dominant_wave_period`| seconds    | `tp_dominant`                    | `period_dominant`              | `period_dominant`             |
| `wind_direction`       | degrees    | `dir_wind` (0–360)                | `dir_wind` (0–360)              | `dir_wind_rad` → convert rad→deg |
| `wind_speed`           | m/s        | `spd_wind`                        | `spd_wind`                      | `spd_wind`                     |
| `tide_stage`           | categorical| `tide_stage` (raw)              | `tide_stage`                    | `tide_stage`                   |
| **Quality Flags**      | -          | N/A                              | N/A                             | N/A                           |

### **Handling Missing Fields**
- If a firmware variant lacks a target column, the field is treated as `missing`.
- Offshore stations (Firmware v3) drop `water_temp` entirely.

---

## **2. Cleaning Rules**

### **Wave Height Clamping & Flagging**
```python
def flag_wave_height(value):
    if value > 25 or value < 0:
        return "suspect"  # Physical implausibility
    return None  # Good data
```

### **Spike Detection & Correction**
- **Threshold**: Wave height spikes > 8σ from rolling 1-hour median.
- **Rule**:
  - Short sequences (<3 consecutive samples) → flagged `corrected` (median-replaced).
  - Longer sequences → flagged `suspect` (preserved as-is).

### **Wind Direction Normalization**
```python
def normalize_wind_dir(value):
    return ((value % 2π) * (180/π)) % 360  # Convert rad→deg, clamp to [0–360]
```

### **Tide Stage Derivation**
- Uses a published threshold table (e.g., `{+1.5m: "high", -0.5m: "low"}`).
- If raw tide gauge reading falls outside thresholds → `missing`.

---

## **3. Gap Handling**

### **Representation**
- Missing values in Parquet are represented as `NaN` for numeric fields.
- Quality flag `missing` applied to all gaps > 4 consecutive windows.

### **Interpolation Policy**
- Gaps ≤ 40 minutes → linear interpolation with `corrected` flags.
- Gaps > 40 minutes → no interpolation; rows dropped (not silently absorbed).

---

## **4. Validation Invariants**

| Invariant                          | Check Method                                                                 |
|------------------------------------|------------------------------------------------------------------------------|
| No duplicate station-window pairs   | Post-processing deduplication by `(station_id, window_start_utc)`.          |
| Window starts aligned to 10-min     | `window_start_utc % 600 == 0` (UTC).                                       |
| Wind direction in [0–360]           | Pre-validated via `normalize_wind_dir()`.                                   |
| Quality flags from closed set       | Enforced via regex: `^good|suspect|corrected|missing$`.                          |
| All target columns present          | Schema validation against fixed Parquet schema.                              |
| Row counts per station/month        | Compare input records → windowed output rows (error if mismatch).             |

---

## **5. Reproducibility**

### **Sorting & Aggregation**
- Sort by `station_id` → `window_start_utc` before aggregation.
- Tie-breaker for identical timestamps: prefer the sensor with lower `wave_height_mean`.

### **Fixed-Precision Formatting**
- Floats serialized to 6 decimal places (e.g., `0.123456` instead of `0.123456789`).

---

## **6. Schema Evolution & Error Handling**

### **Unknown Firmware Variants**
- If records lack mapped fields → pipeline fails with diagnostic:
  ```json
  {
    "error": "Unmapped firmware variant detected: missing required fields [X, Y]",
    "fields": ["X", "Y"]
  }
  ```

---

## **7. Log Fields (Per-Stage)**
| Stage               | Metrics                                                                     |
|---------------------|---------------------------------------------------------------------------|
| Input File Path     | `input_file_path`                                                          |
| Record Counts       | `raw_records`, `cleaned_records`, `windowed_rows`                           |
| Flagged Rows         | `spikes_corrected`, `wave_height_suspect`, `tide_stage_missing`            |
| Wall-Clock Duration | `processing_time_seconds`                                                  |

## **8. Worked Example: Firmware v2 Spike**
**Raw Input (Firmware v2):**
```json
{
  "station_id": "ST10",
  "timestamp": "2023-11-15T08:45:00Z",  # UTC
  "wave_height_mean": 1.2,
  "wave_height_max": 2.3,
  "period_dominant": 6.7,
  "dir_wind": 90,                     # deg
  "spd_wind": 8.5,
  "tide_stage": "high",
  "_gap_marker": null                 # No dropout marker (field absent)
}
```

**Processing Steps:**
1. **Mapping**:
   - `wave_height_mean` → `1.2m` (no unit conversion).
   - `dir_wind=90°` → normalized to `90°`.
   - Tide stage derived from thresholds.

2. **Spike Check**:
   - Assume rolling median = 1.5m, σ=0.3m.
   - Max wave height (`2.3m`) is within bounds → no flag.

3. **Output Row** (Parquet):
```json
{
  "station_id": "ST10",
  "window_start_utc": "2023-11-15T08:40:00Z",  # Aligned to 10-min
  "wave_height_mean": 1.2,
  "wave_height_max": 2.3,
  "dominant_wave_period": 6.7,
  "wind_direction": 90,
  "wind_speed": 8.5,
  "tide_stage": "high",
  "quality_flags": {"wave_height_mean": "good", ...}
}
```
