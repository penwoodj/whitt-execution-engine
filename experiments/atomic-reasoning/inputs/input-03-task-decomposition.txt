# Input 03 — Task Decomposition

## Task
Break the following user request into 3-5 atomic tasks. Each task must be a
single sentence starting with a verb. Do NOT add story points, GWT criteria,
or any other structural metadata — just the task sentences.

## User request
"I want to add a /health endpoint to the Express server that returns JSON
with status, uptime, and currently-loaded models. It should respond in
under 50ms and be rate-limited to 100 req/min."

## Required output format
1. <task sentence>
2. <task sentence>
3. <task sentence>
(4 and 5 optional)
