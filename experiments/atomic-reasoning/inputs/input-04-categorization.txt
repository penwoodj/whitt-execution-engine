# Input 04 — Categorization

## Task
Assign each of the following 5 tasks to exactly ONE category. Categories:
GENERATE (produce new content), VALIDATE (check existing content), ROUTE
(decide next step), TRANSFORM (modify format/structure), EXECUTE (run
external command).

Output one line per task: `TASK_<id>: <CATEGORY>`

## Tasks
T1: Read the user's config file and extract the API endpoint URLs.
T2: Check whether the generated YAML file conforms to schema version 2.0.
T3: Convert the markdown table into a CSV file.
T4: Decide whether to retry the model call or escalate to a human.
T5: Run the test suite and capture the exit code.
