## Project Origins

The YAML to Rust AgentSDK framework was created in 2024 to address the gap between:

1. **Manual AI agent development** - Writing imperative code for every workflow
2. **YAML-based configuration** - Declarative definition without execution engine
3. **Local LLM inference** - Running models efficiently on local hardware

The goal is to provide a **production-ready, type-safe, high-performance framework** for defining, executing, and optimizing AI-powered workflows with local LLMs.
