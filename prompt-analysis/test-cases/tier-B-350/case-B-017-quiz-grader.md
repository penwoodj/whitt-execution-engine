# Tier-B Case 017 — quiz grader (SYNTH)

a grader for a multiple-choice quiz, /tmp/opencode/quizgrade. fixture: an answer key file, 30 questions, single letter answers, plus 20 student submission files each answering all 30, with dirt: some submissions use lowercase, some have spaces after letters, two students left blanks, one student answered 31 questions with a duplicated row, and one submission has every answer as the same letter, suspicious but graded honestly. the grader: normalize answers, case and whitespace, handle blanks as wrong not as crashes, handle the 31-answer case with a stated rule, extra answer ignored and flagged. score each student, percentage, rank them, and flag the all-same-letter submission with a note, not an accusation, just a flag. deliverables: grades.csv with student, raw, percentage, rank, flags, and a stats.md with the class distribution, mean, median, high, low, and the 5 hardest questions by wrong-count. verify: hand-check two student scores against the key in the report, show the per-question comparison for those two. standard library, deterministic, paste the top 3 and the hardest question in chat.

grading rules pinned before any marking: exact string match after trim and case-fold, unanswered is blank is wrong, no partial credit, and multiple answers to one question takes the last, with the conflict logged. the answer key is a file, not code, so swapping keys reruns cleanly, and the per-question difficulty stat, fraction correct, finds the questions that fooled everyone. the score table shows raw score, percent, and letter by the stated cutoffs, 90, 80, 70, 60, and the cutoffs live in a config line i can change. verifier recomputes two scores by hand-logic independently and compares. paste the top of the leaderboard and the hardest three questions in chat, and note any student whose answers are byte-identical to another's, since that's a finding too. also report the class mean and median next to the leaderboard, because one number without the other always hides the shape.
