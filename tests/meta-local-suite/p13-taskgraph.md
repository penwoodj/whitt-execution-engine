# Task: Task Graph Scheduler

Write a Python tool named taskgraph.py using only the standard library. It reads a JSON file (path as first CLI argument) shaped like {"tasks": [{"id": "A", "duration": 3, "deps": []}, {"id": "B", "duration": 2, "deps": ["A"]}, ...]}. It must print exactly two lines: first `ORDER: ` followed by a valid topological ordering of all task ids separated by single spaces (dependencies always before dependents); second `CRITICAL_PATH_LENGTH: <n>` where n is the length of the longest dependency chain measured as the sum of durations along that chain (the earliest possible finish time of the whole project). If the graph contains a cycle print `ERROR: cycle detected` to stderr and exit 1. A missing or invalid file also exits nonzero with a clear error, never a traceback.
