# Task: Log Rotation Script

Write a bash script named rotate.sh that takes a directory and a size threshold in bytes as its two CLI arguments. For every file matching *.log at the top level of the directory whose size is strictly greater than the threshold: shift existing archives up (name.log.2 becomes name.log.3, name.log.1 becomes name.log.2 — keep at most 3 archives, the oldest is deleted), move the file to name.log.1, create a new empty name.log in its place, and print `ROTATED: <name>.log`. Files at or under the threshold are untouched. Print `DONE: rotated=<n>` as the final line and exit 0. The script must run under macOS /bin/bash 3.2 (no associative arrays, no GNU-only flags — note that stat -c is GNU; use wc -c or stat -f on macOS, or a portable approach). A missing directory prints an error to stderr and exits 1.
