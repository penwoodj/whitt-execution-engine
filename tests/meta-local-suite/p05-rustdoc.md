# Task: Rust Public API Extractor (repo-aware)

First inspect the real file src/client/http_client.rs in this repository (read it with shell commands) to understand its public API. Then write a Python script named rustapi.py that, given any Rust source file path as its first CLI argument, extracts every public function signature (lines matching `pub fn` and `pub async fn`, including multi-line signatures up to the opening brace) and prints a markdown table with columns Name | Async | Signature. The script must use only the Python standard library, handle a missing file with a clear error and nonzero exit, and print the table to stdout. Finally include in your deliverable a sample of the table produced for src/client/http_client.rs showing at least 5 of its public functions (e.g. new, health, load_model, unload_model, chat_completion).
