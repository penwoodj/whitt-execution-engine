# Task: Directory Diff Script

Write a bash script named dirdiff.sh that compares two directories given as its first and second CLI arguments (files at the top level only, no recursion required). For every file present in the second directory but not the first print `ADDED: <name>`; present in the first but not the second print `REMOVED: <name>`; present in both but with different content (compare with cmp -s) print `CHANGED: <name>`. Print those lines sorted alphabetically by file name within each category, categories in the order ADDED, REMOVED, CHANGED. Finish with exactly `SUMMARY: added=<a> removed=<r> changed=<c>`. The script must run under macOS's /bin/bash 3.2 (no associative arrays, no GNU-only flags) and exit 0 on success. If either directory does not exist print an error to stderr and exit 1.
