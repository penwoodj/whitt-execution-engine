# Task: Lines-of-Code Reporter (repo-aware)

First inspect the src/client/ directory of this repository with shell commands (ls, wc -l on a couple of .rs files) to see what realistic Rust module sizes look like. Then write a Python tool named locreport.py using only the standard library: given a directory path as its first CLI argument, it recursively finds every *.rs file, counts its lines, and prints a markdown table with header `| File | Lines |`, one row per file as `| <path relative to the given directory> | <line count> |` sorted by path, and a final row `| TOTAL | <sum> |`. Empty directories (no .rs files) print only the header and a TOTAL row of 0. A missing directory prints a clear error to stderr and exits nonzero without a traceback. Include in your deliverable a sample table for this repository's src/client/ directory.
