## Docs Formatting Standards

- Each file gets AT MOST ONE `## 🔗 Related Documentation` section
- Place at the END of the file
- Use relative markdown links, NOT Foam [[WikiLink]] syntax for cross-directory links
- Foam links OK for same-directory references only

### Link Paths
- Always use correct relative paths from source file location
- Verify target file exists before adding link
