# Deep Research

Research orchestration and execution framework for the AgentSDK Execution Engine. Six specialized research streams produce findings that integrate into implementation phases through explicit evidence gates and validation criteria.

## Research Documents

- 00-research-master-plan.md - Master research orchestrator defining methodology, evidence gates, and completion criteria for all research streams
- 01-yaml-schema-research.md - YAML parsing strategies, schema validation approaches, and type mapping patterns
- 02-rust-ecosystem-research.md - Crate selection, alternatives, integration patterns, and dependency analysis
- 03-llm-backend-research.md - LLM backend API protocols, streaming formats, and unified trait design for LM Studio, Ollama, llama.cpp, and OpenAI
- 04-agent-patterns-research.md - Agent orchestration patterns, multi-agent coordination, and Rust implementation approaches
- 05-testing-strategy-research.md - Unit, integration, and E2E testing strategies, mock approaches, and CI integration
- 06-performance-research.md - YAML parsing performance, async runtime tuning, optimization priorities, and scalability targets

## Research Integration

Each research document follows a standardized template:
- Research questions being answered
- Findings with 2+ evidence sources (URLs, versions, dates)
- Recommendations with rationale, trade-offs, and alternatives
- Integration instructions with file locations and code patterns
- Validation criteria with measurable outcomes
- Anti-goal-drift checkpoints
