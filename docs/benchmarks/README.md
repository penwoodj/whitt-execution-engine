# Benchmarks

Consolidated benchmark documentation for the Whitt Execution Engine.

## Structure

- **`workflows/`** - YAML benchmark configurations (3, 5, 15, 50 model benchmarks)
- **`userflows/`** - 20 detailed userflow specifications for 100-model benchmark
- **`plans/`** - Gap analysis, implementation plan, specs, and QA plan

## Overview

This directory contains all benchmark-related documentation:
- Multi-model benchmark workflows (YAML format)
- Comprehensive 100-model benchmark userflows (uf01-uf20)
- Implementation plans and specifications
- QA and validation criteria

See individual subdirectories for detailed documentation.
